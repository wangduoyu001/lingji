# LingJi 模块文档入口

本目录只有两份“活”的导航文档：

- `CODE_MAP.md`：当前代码入口、模块所有权、相关测试和局部验收命令。
- `FUTURE_DEVELOPMENT_TODO.md`：尚未进入当前阶段的未来需求；不能直接覆盖当前开发顺序。

其余 `P0_*`、`P2_*` 文件是对应历史分支或里程碑的实施记录。它们可以证明当时的设计、范围和测试承诺，但：

- 不代表当前分支、当前完成度或当前阻塞；
- 不得覆盖 `docs/PROJECT_STATUS.md`；
- 不得覆盖 `docs/ARCHITECTURE.md`；
- 不得因为写着 `READY`、`MERGED` 或 `IMPLEMENTED` 就推断当前产品已验收；
- 文件中引用的旧分支、旧入口和旧状态只用于历史追踪。

当前开发任务从 `AGENTS.md` 开始，按最小读取顺序进入 `PROJECT_STATUS.md` 和 `CODE_MAP.md`。
