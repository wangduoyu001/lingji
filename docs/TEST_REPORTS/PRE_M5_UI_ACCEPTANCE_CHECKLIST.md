# Pre M5 UI Acceptance Checklist

## Goal

Verify LingJi works as a second brain before expanding opportunity features.

## UI acceptance

- Home answers: what is LingJi doing, what was completed, does it need the owner.
- Work shows real WorkItem progress and outcome.
- Attention only shows concrete PendingAction.
- Memory shows source and evidence.
- Capture shows receive -> processing -> completed states.

## Rules

- UI must not infer work from memory count or generic events.
- Empty states must be explicit and honest.
- Normal operation should require no manual intervention.
- Manual confirmation is only required for owner decisions.
