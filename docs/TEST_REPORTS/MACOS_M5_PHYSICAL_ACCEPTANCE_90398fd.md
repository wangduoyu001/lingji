## 阻塞缺陷

### M5-UX-003 · 进度看板仍停留在统计层

- 严重级别：P1
- 影响：首页主要承担进度理解的目标尚未完成。
- 实际：已展示收纳、更新、覆盖等信息，但缺少清晰的工作链路、变化量、最近成果、异常自动处理过程、待决事项与可追溯取回质量。
- 预期：首页能够让主人一眼理解“系统刚做了什么、正在做什么、接下来会做什么、何时需要我决定”，并能向下查看细节。
- 修复范围：将记忆生命周期组织为可展开的进度链路；补充真实变化量、最近更新时间、失败/重试、取回验证样本与量化质量指标。未经验证不得把覆盖率称为准确率。

### M5-PROCESS-001 · 首次替换安装流程偏离

- 严重级别：P1（验收流程）
- 实际：备份目录未创建时，首次替换没有在预期的整体移动处停止；签名校验立即失败。随后已将不完整 App 隔离，并从 DMG 重新做完整安装且签名通过。
- 数据影响：未触碰 Production 数据目录；本轮 Runtime 数据仍位于 task-scoped 根目录。
- 结论：不能把这次首次替换当作无偏差的升级/回滚验收；后续复验必须先验证备份目录，再执行 whole-bundle replace。
