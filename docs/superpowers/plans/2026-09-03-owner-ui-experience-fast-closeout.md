# 灵机主人界面快速收口计划

> 日期：2026-09-03  
> 分支：`codex/owner-memory-detail-drilldown`  
> 目标：不增加产品能力，不重构记忆、向量或 RAG；用一次集中实现、一次独立审查和一次 Mac 真机体验，把现有能力做成主人看得懂、愿意用的产品。

## 1. 本轮成功标准

主人打开灵机后，无需操作即可看见：

- 灵机最近自动接管了哪些来源、多少对话和消息；
- 最近新形成的具体记忆，而不是只有统计数字；
- 每条记忆的当前结论、变化过程、是否仍有效和来源；
- 点击后可核对正文、原始证据及原始/结构化/向量/长期记忆状态；
- 只有高风险、Core 或真实冲突时才出现“需要我”，其余流程自动完成。

普通界面不得显示已被新版本替代的内容，不得把扫描、暂停、撤销、逐条确认做成日常主流程。

## 2. 执行策略调整

体验候选只保留四类阻断门禁：

1. 数据与隐私安全边界没有被破坏；
2. 已授权的真实 AI 对话能够被导入，重复扫描不会制造重复数据；
3. 普通记忆卡能够追溯到真实来源，不能用虚构摘要冒充记忆；
4. Mac arm64 应用可以构建、启动、遍历核心页面并正常使用。

旧 Task4R2/Task7 系列质量测量、全仓库历史失败和非本轮视觉 Minor 记录为非阻断技术债务，不得冒充通过，也不得阻止生成主人体验候选。最终正式合并仍需另行决定如何收口。

## 3. Task A — 权威任务切换

- 如实结束旧 runtime focused 任务：已完成的修复保留；packaged 双轮作为本轮真实导入门禁继续验证。
- 激活唯一短周期任务 `OWNER_UI_EXPERIENCE_FAST_CLOSEOUT`。
- 冻结本计划的页面、菜单和验收范围，开发期间不再追加新功能或新质量门。

## 4. Task B — Luna 一次性 UI 与菜单改造

仅修改现有 Desktop UI、主人视图适配器和对应测试；不得新增数据库、后端、API、队列、检索器或状态源。

### 菜单

普通导航固定为三个入口：

- `首页`：最近自动成果、最近记忆、正在处理和真实待办提醒；
- `我的记忆`：current-only 记忆主页面；
- `来源`：发现、授权、接管规模和最近检查。

`需要我` 不再永久占主菜单。仅有真实待办时，在首页显示入口或徽标。高级页面不删除路由，全部收进一个“高级诊断”入口，并在诊断页内按运行与错误、数据与索引、模型与算力、存储与备份分组。

### 首页

- 第一视觉焦点是“最近自动记住的具体内容”，不是四个大数字；
- 显示最近自动接管成果：来源、对话数、消息数、最近检查时间；
- 显示当前正在处理什么；空闲时用简短文案，不展示 JSON；
- 没有真实待办时不显示待办入口；
- 任何内部 ID、Hash、端口、原始状态词只允许在折叠技术详情中出现。

### 我的记忆

- 普通列表只显示 `current`，`superseded/stale/archived/invalidated/rejected` 不出现；
- 卡片直接显示“一件事、当前结论、最近变化、来源、长期记忆状态”；
- 点击进入稳定右侧抽屉或双栏详情，显示完整正文、时间线、来源原文和四层状态；
- 原始/结构化/向量/长期状态使用紧凑轨迹，不使用四个同权重大徽章；
- 修改、标记过时、移出和删除仅放在折叠“备用操作”；
- 默认不要求主人逐条确认低风险记忆。

### 来源

- 普通视图只显示来源是否发现、是否接管、已导入规模、最近检查和限制原因；
- 授权是首次必要动作；扫描、暂停、重试、撤销放在来源详情或故障工具中；
- Claude 等官方不支持旧历史时给出准确简短说明，不显示没有可执行按钮的“下一步”；
- 不把“检测到软件”写成“已经接管”。

### 视觉

- 采用温暖、安静的个人知识库风格，减少管理后台感；
- 统一页面最大宽度、留白、标题层级、颜色、圆角和阴影；
- 降低边框、表格、胶囊和警告色密度；
- 保持键盘焦点、Escape 关闭详情、窄窗口可用和正文可滚动；
- 优先整理主人界面专用 CSS，不无边界重写全站样式。

## 5. Task C — 一次独立审查与最多一轮修复

独立审查只允许以下问题阻断：

- 页面无法打开、菜单死路或构建失败；
- 看不到具体记忆正文或来源证据；
- 旧版本出现在普通列表；
- 普通页面暴露敏感路径、凭证或无界技术数据；
- 自动流程被退化为必须手动扫描或逐条确认；
- 来源/数量/状态与后端真实数据明显矛盾；
- 真实导入和重复扫描门禁失败。

纯审美偏好、轻微间距、非核心高级页和旧质量测量只记录，不触发多轮循环。最多一轮必要修复。

## 6. Task D — Mac 主人体验验收

- 运行本轮 focused UI 行为测试和 Desktop build；
- packaged 自动扫描 clean-root 完整流程连续通过两次；
- 从精确产品 SHA 构建并 whole-bundle 安装 Mac arm64 App；
- 使用隔离 Acceptance 根，不读取或修改 Production/Vault/主人真实数据；
- 遍历首页、我的记忆、来源和高级诊断入口；
- 至少打开 5 条不同类型的记忆，逐条核对正文、发展、当前结论、来源原文和四层状态；
- 验证普通列表没有旧版本，空待办不会占主菜单，自动扫描不依赖主人点击；
- 保持 App 打开，等待主人最终确认。

主人未确认前，只能写“技术验收通过，等待主人体验”，不得宣布 Phase 1、release 或最终合并完成。
