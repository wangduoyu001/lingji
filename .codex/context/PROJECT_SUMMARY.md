# LingJi Second Brain

This worktree adds an isolated memory service alongside the existing LingJi PEMIS service. The original service remains in `C:\Users\Administrator\Documents\New project-ai` on `master` and keeps its original startup chain.

The second brain stores traceable AI-chat archives and reviewable structured memories. It indexes user-authored Obsidian Markdown as formal knowledge without distilling it into memories.
