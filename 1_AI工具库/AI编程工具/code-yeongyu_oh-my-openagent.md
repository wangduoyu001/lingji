# Oh-My-OpenAgent — 用"最便宜"的模型跑出最优效果

> ⭐ 63,029 | 📅 2026-06-20 | [GitHub](https://github.com/code-yeongyu/oh-my-openagent)

## 干什么

Oh-My-OpenAgent（OmO）是一个给 AI 编程工具"打鸡血"的插件。它最核心的创新是**多模型智能调度**——不同类型的任务自动分配给最擅长那个类型的模型：前端 UI 给视觉能力强的模型、复杂逻辑给推理能力强的模型、简单任务给便宜的模型。

没它之前，你用 AI 编程工具就是"一个模型干所有活"——写前端也是它、写后端也是它、调试 bug 也是它。问题是，没有一个模型在所有任务上都是最强的。OmO 的做法是，把任务自动分派给最合适的模型，实现"花最少的钱，干最好的活"。

实际效果：有用户反馈只靠 ChatGPT（$20/月）+ Kimi Code（$19/月）+ GLM Coding（$10/月）三个低价订阅，就能流畅运行 OmO 的全部功能，效果不输给单独用昂贵模型。

## 能实现什么效果

OmO 的"乌尔特拉工作"（ultrawork）模式是最亮眼的功能：你输入任务描述，它会自动规划、并行派发给不同模型执行、自动检查结果、循环迭代直到完成。你不需要关心"用哪个模型干哪一步"——它自动帮你决策。

团队模式更猛：1 个主 Agent + 最多 8 个并行成员 Agent，你能在 Tmux 窗口里实时看到各个 Agent 的工作进度。比如你在做一个全栈项目，Agent A 在写前端组件、Agent B 在写 API、Agent C 在写测试、Agent D 在修 bug——同时进行。

还有个很实用的功能叫"哈希锚点编辑"：让 AI 编辑代码时，每行代码带一个内容哈希值，避免因为文件内容变化导致编辑错行。这个功能让 AI 代码编辑的成功率从一个惨不忍睹的 6.7% 提升到了 68.3%。

## 怎么用

- **终极版（OpenCode 专用）**：`bunx oh-my-openagent install` → 交互式配置引导 → 选模型 → 搞定。
- **轻量版（Codex CLI 专用）**：`npx lazycodex-ai install` → 装到 Codex 里 → 配置 → 搞定。
- **开启 ultrawork**：在 OpenCode 里输入 `/ulw 帮我做一个待办事项 App` → 自动规划、并行执行、自动验证。
- **开启团队模式**：`/ulw --team 做一个全栈博客系统` → 多个 Agent 同时开工。
- **安全审计**：`/security-research` 让多个 Agent 并行扫描代码库找漏洞。

## 运行位置

- 本地电脑（macOS / Linux / Windows），作为 OpenCode 或 Codex CLI 的插件运行
- 支持 Tmux 终端可视化监控

## 需要准备什么

- 免费开源但协议需要注意（非标准 MIT）
- 需要 OpenCode（终极版）或 Codex CLI（轻量版）
- 需要至少一个大模型的订阅/API Key（可以用便宜的，组合使用效果反而好）
- 安装工具：Bun 或 Node.js
- 电脑配置：普通笔记本就行（AI 推理在云端）

## 配合什么软件

- 必须配合 **OpenCode**（终极版）或 **Codex CLI**（轻量版）
- 可选配合 Tmux（可视化团队模式进度）
- 内置 MCP 工具自动生效（Exa 搜索、Context7 文档查询、Grep.app 代码搜索）

## 客观评价

**优点**：多模型智能调度思路领先——"花最少的钱拿最好的效果"直击 AI 编程成本痛点；ultrawork 自动推进模式极大减少了人工干预；哈希锚点编辑大幅提升了代码编辑可靠性（6.7% → 68.3%，虽然 68% 也算不上完美）；团队模式可视化很酷。

**缺点**：安装和配置比较折腾——不是一条命令就好的那种，最好让 AI 帮你装；依赖 OpenCode 或 Codex CLI，自己不算独立工具；文档偏技术流，新手容易晕；协议不是 MIT，商用需要看清楚条款；部分高级功能稳定性一般。

**适合谁**：经常用 AI 写代码且对成本敏感的人、想做复杂多模块项目的开发者、对 AI Agent 编排感兴趣的研究者。**不适合**：AI 编程新手（入门门槛高）、只想简单改改代码的人。

**评分 7/10**：多模型调度的思路很棒，哈希锚点编辑是实用创新。但安装和配置体验拖了后腿。

## 未来趋势

项目处于**快速增长期**，更新频繁（几乎每天都有提交）。随着模型种类越来越多且价格持续下降，多模型调度的价值会越来越大。

**关注度 4/5**：多模型智能调度的方向非常有前瞻性，但这个领域竞争激烈。
