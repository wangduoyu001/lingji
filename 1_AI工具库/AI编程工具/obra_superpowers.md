## 干什么

superpowers 是一套"让 AI 写代码之前先想清楚"的方法论和技能框架。它的核心理念很简单但极其管用：不让 AI 上来就写代码，而是先搞清楚你到底要什么 → 写一份需求说明 → 逐段跟你确认 → 制定实现计划 → 最后才动手写代码。这就像找一个靠谱的程序员——差的程序员拿到需求直接开写，写到一半发现理解错了；好的程序员会先跟你聊半小时，确认每个细节，再动键盘。superpowers 就是给 AI 编程代理戴上了一个"先想后做"的紧箍咒。

## 能实现什么效果

用了 superpowers 之后，你让 AI 写一个从零开始的功能模块，它不会再给你产出 500 行乱七八糟的代码让你改半天。而是先给你一份清晰的 spec（需求说明书），包含要实现什么、边界条件是什么、怎么测试，你确认后再生成代码。实测数据显示，这种方式可以减少 60%-80% 的返工次数。最终产出的代码质量明显更高——因为 AI 不是瞎猜你的意图，而是按照确认过的规范来写。项目包含了大量可复用的 skills（技能模块），覆盖了常见开发场景。

## 怎么用

- **新功能开发**：想做一个用户登录系统 → 打开 Claude Code/Codex CLI → 加载 superpowers skill → AI 先跟你确认"用什么方式登录？要不要验证码？错误几次锁定？" → 确认后自动生成代码和测试
- **Bug 修复**：发现一个奇怪的 bug → 加载 bug-fixing skill → AI 先分析可能原因 → 跟你确认症状 → 再动手修改
- **代码重构**：老代码一团乱麻 → 加载 refactor skill → AI 先理解现有逻辑 → 跟你确认不变更的行为 → 生成重构后的干净代码
- **文档生成**：代码写完了没文档 → 加载 documentation skill → AI 自动读取代码 → 生成结构化的 API 文档
- **代码审查**：同事提交了 PR → 加载 review skill → AI 自动检查代码风格、潜在 bug、性能问题

## 运行位置

- **本地电脑**（Shell 脚本为主）：Windows/Mac/Linux 都能用
- 本质上是给 AI 编程工具（Claude Code、Codex CLI、Cursor 等）添加的"技能包"
- 不是独立应用，不自己运行模型

## 需要准备什么

- **费用**：完全免费开源（MIT 协议）
- **账号**：不需要
- **API Key**：需要有至少一个 AI 编程工具（Claude Code、Codex CLI、Cursor 等），这些工具本身需要 API Key
- **电脑配置**：只要能跑 AI 编程工具就行，superpowers 本身几乎不消耗资源（纯文本配置文件）
- **软件依赖**：需要 Git 来克隆仓库

## 配合什么软件

必须配合 AI 编程工具使用（不能独立使用）：Claude Code、Codex CLI、Cursor、Aider、OpenCode 等。就像一个游戏 mod，不能脱离游戏本体运行。

## 客观评价

优点：① 理念实在——"先想后做"减少了大量返工，特别适合复杂项目；② 免费开源，只有纯文本配置，没有任何隐藏成本；③ 社区活跃（23 万星），skill 种类多、更新快；④ 跨 AI 工具通用——不绑死某一个 AI 编程工具。

缺点/坑：① 不能独立使用，如果还没有 AI 编程工具的基础，需要先搭好环境；② 配置文件偏技术向，非程序员完全看不懂；③ 部分 skill 质量参差不齐——社区的 skill 不像官方产品那样经过严格测试；④ 用 superpowers 后，AI 跟你确认的步骤变多了，有时会觉得啰嗦。

适合谁：重度 AI 编程用户、做复杂项目的开发者。不适合：只是想快速生成小脚本的轻度用户、完全不懂编程的人。

打分：8.5/10。23 万星不是白来的——它解决了"AI 代码质量不稳定"这个核心痛点。扣 1.5 分因为对非程序员不友好，以及依赖第三方 AI 工具。
