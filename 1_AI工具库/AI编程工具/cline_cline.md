## 干什么

Cline 是一个"什么都能干的 AI 编程助手"——它不只是帮你写代码，还能自己规划任务、自己运行命令、自己测试、甚至自己部署。你可以把它想象成"一个不用睡觉、不会抱怨、24 小时待命的高级程序员"，你告诉它要做什么，它自己想办法搞定。

它最厉害的地方是"多形态"：你可以在 VS Code 里当插件用（最方便）、在终端里当命令行工具用（适合脚本自动化）、用 SDK 自己集成到项目里（适合高级玩家）、甚至用 Kanban 任务板同时跑多个代理一起干活（适合大型项目）。一套核心，五种用法，想怎么用就怎么用。

它是完全开源的（Apache 2.0 许可证），不是某家公司的封闭产品。支持几乎所有市面上能见到的大模型——Anthropic 的 Claude、OpenAI 的 GPT、Google 的 Gemini、甚至你自己在本地跑的开源模型（通过 Ollama 或 LM Studio）都能接入。相当于"一个遥控器控制所有 AI"。

## 能实现什么效果

举个例子：你要做一个完整的用户登录功能，包括前端页面、后端 API、数据库表结构设计。以前你要自己写前端表单、后端接口、数据库迁移脚本、测试用例，可能要花一两天。用 Cline，你在 VS Code 里跟它说："帮我做一个完整的用户登录功能，包括注册、登录、登出、密码重置，用 React 前端 + Express 后端 + PostgreSQL 数据库"——它会自己规划步骤：先设计数据库表 → 写迁移脚本 → 写后端 API → 写前端页面 → 写测试。每个步骤它会先跟你确认，你满意了它再执行。原本一两天的活，可能两三个小时就搞定了。

另一个例子：你有一个跑了很久的项目，想做一次依赖包更新，但又怕更新完之后项目挂掉。手动一个个查哪些包有安全问题、哪些包可以安全更新、更新完之后要改什么代码，非常花时间。把项目目录告诉 Cline，跟它说"帮我检查并更新所有有安全漏洞的依赖包，更新完后跑测试确保项目没问题"——它会自己查 package.json、比对最新版本、逐个更新、跑测试、修复因为版本变化导致的兼容性问题。相当于身边有个超级细心的技术负责人帮你做代码审查和质量保障。

它还能做定时任务。比如你希望每个工作日早上 9 点自动检查项目里有哪些待审核的 PR（Pull Request）、自动生成摘要发到 Slack。用 Cline 的定时任务功能，设置一次，它就会每天自动跑，完全不用你操心。

## 怎么用

- **VS Code 里写代码**：安装 Cline VS Code 插件 → 在侧边栏打开 Cline → 说"帮我把这个函数的命名改得更清楚，并更新所有引用" → 它改完展示 diff（差异对比），你确认后保存 ✓
- **终端里自动化任务**：运行 `cline "运行测试并修复所有失败的用例"` → 它会跑测试、看报错、改代码、再跑测试，直到全部通过
- **多代理协作**：运行 `cline --team-name auth-sprint "规划和实现用户认证功能，包括测试和文档"` → 它会创建一个"协调者"代理和多个"专家"代理（比如一个负责后端、一个负责前端、一个负责测试），分工合作
- **定时任务**：运行 `cline schedule create "每日PR摘要" --cron "0 9 * * MON-FRI" --prompt "列出所有待审核的PR及其状态" --workspace /path/to/repo` → 每个工作日早上自动执行
- **Slack/Telegram 里远程操控**：配置 `cline connect slack` 或 `cline connect telegram` → 在 Slack 消息里跟它对话 → 它帮你改代码、跑测试、部署，你在手机上就能遥控整个项目

## 运行位置

- 🖥️ **Windows / Mac / Linux 都可以**：有 VS Code 插件版、终端 CLI 版、JetBrains 插件版，覆盖所有主流平台
- 需要联网（调用云端 AI 模型），也支持本地模型（Ollama/LM Studio）完全离线运行
- VS Code 插件版：在 VS Code 里直接使用，最方便
- 终端 CLI 版：在任意终端里运行，适合脚本和自动化
- 桌面独立版：正在开发中，未来会有独立应用
- Kanban 网页版：运行 `npm i -g kanban` 启动网页任务板，在浏览器里管理多代理任务

## 需要准备什么

- 💰 **要钱吗**：Cline 本身是开源免费的。但用哪个 AI 模型就付哪个的钱。如果用 Anthropic 的 Claude，需要付 API 费用（按量计费，一个月几十到几百块不等，看用量）。如果用本地模型（Ollama），完全不用钱，但需要一个好点的显卡
- 🔑 **API Key**：根据你选的模型，需要对应的 API Key。用 Claude 就填 Anthropic API Key，用 GPT 就填 OpenAI API Key，用 Gemini 就填 Google API Key。也可以填 OpenRouter 的 Key（一个 Key 能用 200+ 模型）
- 💻 **电脑配置**：要求不高，普通办公电脑就能跑 CLI 和 VS Code 插件。如果要跑本地模型，需要好点的显卡（8GB 显存起步，推荐 16GB+）
- 📦 **要装什么**：
  - VS Code 用户：在 VS Code 插件市场搜索 "Cline" 安装（最简单）
  - 终端用户：运行 `npm i -g cline` 安装 CLI
  - JetBrains 用户：在 JetBrains 插件市场搜索 "Cline" 安装
  - Kanban 用户：运行 `npm i -g kanban` 安装网页任务板
- 🌐 **网络**：用云端模型需要能访问对应的 API 服务器。用本地模型（Ollama）完全不需要联网

## 配合什么软件

- **VS Code**：最常用的配合方式，装插件后在侧边栏直接用，改代码时有 diff 预览，非常直观
- **JetBrains 系列**：支持 IntelliJ、PyCharm、WebStorm 等，在 JetBrains 里也能用同样的体验
- **Git**：强烈建议配合 Git 使用，Cline 每次改代码都会创建 checkpoint（检查点），改错了可以一键回退
- **终端**：CLI 模式可以在任意终端里用，适合脚本和 CI/CD 自动化
- **Slack / Telegram / Discord**：可以配置消息平台集成，在聊天软件里远程操控 Cline
- **MCP 服务器**：支持 Model Context Protocol，可以接入各种外部工具（数据库、API、云服务等）

## 客观评价

**优点**：
- 真正开源免费（Apache 2.0），代码完全透明，不用担心厂商锁定
- 支持几乎所有主流大模型，一个工具搞定所有 AI 后端，不用每个模型都装一个工具
- 多形态设计非常实用：写代码用 VS Code 插件、自动化用 CLI、多代理用 Kanban，各取所需
- 定时任务和消息平台集成是独门绝技，适合需要自动化的团队
- Plan 模式和 Act 模式分离，先规划再执行，不容易犯大错
- 支持 MCP 协议，可以无限扩展能力

**缺点/坑**：
- 功能太多太全，新手容易不知道从哪里开始，学习曲线有点陡
- 需要自己准备 API Key（或本地模型），对于完全新手来说配置有点麻烦
- 多代理协作功能虽然强大，但设置复杂，小项目用不上
- VS Code 插件偶尔会和别的插件冲突，需要手动排查
- 定时任务功能需要电脑保持运行（或者用服务器），不是"设一次就永远跑"的那种

**适合谁**：有一定编程经验、希望提升效率的开发者。特别适合需要自动化任务、多模型切换、或远程操控的开发团队。

**不适合谁**：完全零基础想"不写代码做网站"的人（Cline 是给程序员用的工具，不是无代码平台）。

**评分**：8.5/10 — 功能最全面、最灵活的 AI 编程助手，但入门门槛稍高
