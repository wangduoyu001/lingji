## 干什么

Open Interpreter 是一个能在你电脑上直接运行代码的 AI 助手。你可以把它理解成"一个能直接操作你电脑的 AI 员工"——你用大白话告诉它要干什么（比如"帮我把这个 CSV 文件里的数据画成柱状图""帮我下载这个网页的所有图片""帮我整理文件夹里的文件，按类型分类"），它会自己写代码、运行代码、告诉你结果。它不只是"给你代码让你自己复制粘贴运行"，而是真的在你电脑上运行，你看着它操作就行。

它现在（2026 年）已经用 Rust 重写了核心部分，性能和安全性都比以前的 Python 版本好很多。Rust 重写意味着这个工具现在是"生产级"的——更稳定、更快、更安全。以前的 Python 版本现在由社区维护（在 `endolith/open-interpreter`），如果你想用老的 Python 版可以去那个仓库。

它最大的特点是"专为低成本模型优化"——很多 AI 编程工具只能用贵的模型（GPT-4、Claude 等），Open Interpreter 专门优化了让便宜的模型（Deepseek、Kimi、Qwen 等国产模型）也能用好。这样你用起来成本低很多，适合频繁使用。

## 能实现什么效果

举个例子：你有一个 Excel 文件，里面有几万行销售数据，你想"按地区统计销售额、找出 TOP 10 客户、画一个趋势图"。以前你要么手工在 Excel 里点来点去（可能要 1-2 小时），要么自己写 Python 代码（如果不懂编程就搞不定）。用 Open Interpreter，你直接说"帮我分析这个 Excel 文件，按地区统计销售额、找出 TOP 10 客户、画趋势图"，它自己写 Python 代码、运行、生成结果和图表。时间可能从 1-2 小时变成 5 分钟，而且结果更准（不会像手工操作那样点错）。

另一个例子：你需要"每天从某个网站下载一份报告，然后发邮件给团队"。以前你要么每天手动下载、手动发邮件（烦而且容易忘），要么自己写脚本（需要懂编程）。用 Open Interpreter，你说"帮我写一个脚本，每天上午 9 点自动从 XX 网站下载报告、然后发邮件给 XX"，它生成脚本、你测试一下、设好定时任务，之后每天自动跑。相当于雇了一个不用睡觉的助理帮你处理重复性的电脑操作。

它还能帮你做"文件整理"——比如你下载文件夹里堆了几百个文件，各种格式混在一起。你说"帮我把这个文件夹里的文件按类型分类，图片放 images 文件夹、文档放 docs 文件夹、视频放 videos 文件夹"，它自己写脚本、运行、帮你整理好。这种"说一句话让电脑自己干活"的体验，是传统编程工具给不了的。

## 怎么用

- **想快速安装（macOS/Linux）**：在终端里运行 `curl -fsSL https://www.openinterpreter.com/install | sh` → 装完输入 `i` 或 `interpreter` 启动
- **Windows 用户**：在 PowerShell 里运行 `irm https://www.openinterpreter.com/install.ps1 | iex` → 装完输入 `i` 启动
- **想切换模型**：在 Open Interpreter 里输入 `/model` → 选择你想用的模型（支持 Deepseek、Kimi、Qwen、GPT、Claude 等）→ 如果要用的模型需要 API Key，按提示输入
- **想切换" harness "（代理模式）**：输入 `/harness` → 选择你想用的模式（native/claude-code/kimi-cli/qwen-code/deepseek-tui 等）→ 不同模式针对不同模型优化了系统提示词，让模型表现更好
- **想操作浏览器或测试应用**：用内置的 QA skill → 可以让 AI 操作真实浏览器（通过 agent-browser）或操作原生应用（通过 trycua）→ 适合自动化测试场景

## 运行位置

- 🖥️ **本机**：Windows、Mac、Linux 都支持。装完之后在终端里运行，AI 直接在系统上执行代码
- 🔒 **沙箱运行**：有原生沙箱支持（macOS、Linux、Windows 都有），代码在隔离环境里运行，不会弄脏你的系统。这是很大的安全优势——不用担心 AI 写的代码把系统搞坏
- 📱 **没有手机版**：目前只有终端/桌面版，没有手机 App
- 🌐 **ACP 协议支持**：可以当 Agent Client Protocol（ACP）代理运行，和支持 ACP 的编辑器集成（比如某些 AI 编程编辑器）

## 需要准备什么

- 💰 **要钱吗**：开源版免费（Apache 2.0 许可证）。需要付的是大模型 API 费用（如果用云端模型）。推荐用便宜的国产模型（Deepseek/Kimi/Qwen），成本低很多。也可以用本地模型，完全免费
- 🔑 **API Key**：取决于你用的模型。如果用 Deepseek/Kimi/Qwen 等国产模型，需要对应 API Key（这些模型便宜，Deepseek 可能比 GPT 便宜 10 倍以上）。如果用本地模型，不需要 API Key
- 💻 **电脑配置**：能跑 Rust 程序的电脑都行，要求不高。如果用本地模型，需要好一点的显卡
- 📦 **要装什么**：用一键安装脚本最方便（见上方"怎么用"）。也可以自己编译，但需要 Rust 工具链
- 🌐 **网络**：需要能访问你用的模型的 API。如果用本地模型，不用联网

## 配合什么软件

- **终端（命令行）**：主要交互方式，在终端里对话
- **本地模型工具（Ollama 等）**：如果想不付 API 费用、用本地模型
- **agent-browser（Vercel Labs 出品）**：可以让 AI 操作真实浏览器，做网页自动化
- **trycua**：可以让 AI 操作原生应用，做桌面应用自动化测试
- **支持 ACP 的编辑器**：可以当 ACP 代理运行，在编辑器里调用
- **独立使用**：不强制依赖其他软件，装完就能用

## 客观评价

**优点**：
- 专为低成本模型优化，用国产模型（Deepseek/Kimi/Qwen）成本低很多，适合频繁使用
- 有原生沙箱，代码在隔离环境运行，比"直接在你系统上跑代码"安全很多（虽然还是要小心，不要给它太高权限）
- 支持 harness 切换，针对不同模型优化了系统提示词，让便宜的模型也能有好表现
- 用 Rust 重写后性能和安全性提升，现在是生产级工具
- 支持的操作很全面：文件操作、数据分析、网页爬取、浏览器自动化、应用测试都能做
- 开源、Apache 2.0 许可证，可以随便用、随便改

**缺点/坑**：
- 需要写命令/用终端，没有网页界面。不适合完全不懂命令行的人
- 虽然说"沙箱运行"，但如果你不小心给了太高权限，还是有风险。用的时候要注意
- 不同模型表现差异大——贵的模型（GPT-4/Claude）效果好，便宜的模型可能偶尔会理解错你的意思。需要测试找到性价比最好的模型
- Rust 版是全新重写，可能还有一些 bug。如果遇到问题，可以试社区维护的 Python 版（endolith/open-interpreter）
- 文档虽然有不少，但有些高级功能（比如自定义 harness、MCP 集成）需要一定技术背景

**适合谁**：想让 AI 直接操作电脑的人、需要频繁做数据分析/文件处理的人、想用便宜模型但不想牺牲太多效果的人。不适合完全不懂技术的人。

**不适合谁**：想要网页界面、完全不用终端的人（可以用 OpenAI 的 Code Interpreter，但有使用次数限制）、对安全风险零容忍的人（任何能让 AI 运行代码的工具都有风险，需要自己评估）。

**评分**：8/10 — 低成本模型优化 + 沙箱安全 + Rust 重写，是"让 AI 操作电脑"这个方向里的好选择。扣分的点是终端界面对新手的门槛。
