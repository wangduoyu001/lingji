## 干什么

AgenticSeek 是一个"完全跑在你自己电脑上"的 AI 助手——它不搞云端、不传数据、不用联网（如果你用本地模型的话），所有事情都在你电脑上完成。你可以把它想象成"一个住在你电脑里的 Jarvis（钢铁侠的 AI 管家）"，你说话，它干活，数据不出你的房间。

它最厉害的地方是"真的能自己干活"——不是那种"我给你建议你要自己操作"的半吊子 AI，而是能自己打开网页、自己搜索信息、自己写代码、自己运行代码、自己看运行结果、自己调试。比如你说"帮我找个法国雷恩最好的咖啡馆，把前三名保存到文件里"，它会自己打开浏览器、自己搜索、自己读网页、自己提取信息、自己写文件，全程不用你动手。

它是开源项目（MIT 许可证），作者明确说这是"零资金的副业项目"，所以不要指望它有商业产品那样的完善度。但它的核心价值——完全本地化、完全私密——是别的项目做不到的（Claude Code、Cline、Gemini CLI 都需要联网调用云端 AI）。

## 能实现什么效果

举个例子：你在一家公司上班，公司代码不能传外网（这是很多大厂的硬性规定），但你又想要 AI 帮你写代码、改代码。以前你只能自己手写，或者用一个离线的代码补全工具（比如 Copilot 的离线模式，但功能很弱）。用 AgenticSeek，你在自己电脑上装好本地模型（比如用 Ollama 装一个 Deepseek 32B 模型），然后启动 AgenticSeek，跟它说"帮我写一个解析 CSV 文件的 Python 函数，要处理编码问题和缺失值"——它会在你电脑上生成代码、运行测试、调试报错，所有数据都在本地，不会泄露到外网。对于对数据安全有严格要求的企业开发者来说，这是刚需。

另一个例子：你想要一个"能语音对话的 AI 助手"，像电影里那样跟电脑说话、电脑回答你。AgenticSeek 支持语音输入输出（目前只支持英语），你可以设置唤醒词（比如"Friday"），然后说"Friday, 帮我查一下今天有什么 AI 新闻"——它会自己打开浏览器搜索、读网页、总结新闻、语音播报给你。虽然目前语音功能还比较早期，但已经能用了。

它还能做"隐身浏览"——用 undetected_selenium 降低被网站检测的概率，适合需要自动化浏览网页但又不想被反爬虫机制封掉的场浅。比如你说"帮我监控这个电商网站的价格变化，每天记录下来"——它会自己打开网页、读取价格、保存数据，网站很难发现它是机器人。

## 怎么用

- **安装（Docker 方式，推荐）**：先装好 Docker 和 Docker Compose → 克隆仓库 `git clone https://github.com/Fosowl/agenticSeek.git` → 修改 `.env` 和 `config.ini` 配置文件 → 运行 `./start_services.sh full`（Mac）或 `start start_services.cmd full`（Windows） → 访问 `http://localhost:3000` 使用网页界面 ✓
- **安装（CLI 方式）**：克隆仓库 → 运行 `./install.sh` → 运行 `./start_services.sh`（只启动基础服务） → 运行 `uv run python -m ensurepip` → 运行 `uv run cli.py` → 在终端里对话
- **配置模型**：编辑 `config.ini`，设置模型类型（ollama / lm-studio / openai 等）和模型名称 → 如果用本地模型，先装好 Ollama 并下载模型（推荐 14B 或 32B）
- **用语音交互**：在 CLI 模式下，设置唤醒词 → 说出唤醒词 + 你的指令 → AgenticSeek 执行并语音回答（目前只支持英语）
- **自动化任务**：在网页界面或 CLI 里输入复杂任务（比如"搜索 2024 年热门科幻电影，选 3 部保存到 movie_night.txt"） → AgenticSeek 自主规划步骤 → 逐步执行 → 返回结果

## 运行位置

- 🖥️ **Windows / Mac / Linux 都可以**：有 Docker 方式（全平台通用）和 CLI 方式
- 用本地模型的话完全不需要联网（真正离线运行）
- 用云端 API 的话需要联网（但不推荐，失去了"完全本地"的意义）
- 网页界面：启动后在浏览器访问 `http://localhost:3000`
- CLI 模式：在终端里直接对话
- 需要 Docker Engine 和 Docker Compose（如果用 Docker 方式）

## 需要准备什么

- 💰 **要钱吗**：用本地模型完全不用钱！这是最大优势。但你需要自己的硬件（显卡）。如果用云端 API（OpenAI/Deepseek 等），需要付 API 费用。作者明确说这是零资金的副业项目，所以软件本身免费
- 🔑 **API Key**：完全可选！如果用本地模型（推荐），不需要任何 API Key。只有用云端模型的时候才需要对应的 Key（OpenAI API Key / Deepseek API Key 等）
- 💻 **电脑配置**：这是最大的门槛。最低需要 8GB 显存的显卡（跑 7B 模型，但不推荐，效果差），推荐 24GB+ 显存（跑 32B 模型，大多数任务能成功），理想是 48GB+ 显存（跑 70B+ 模型，效果最好）。如果用 CPU 跑，需要大内存（32GB+）且速度很慢
- 📦 **要装什么**：
  - 必选：Git（克隆仓库用）
  - 必选（Docker 方式）：Docker Engine 和 Docker Compose V2
  - 必选（本地模型）：Ollama 或 LM Studio，并下载好模型（推荐 Deepseek 32B 或 Magistral 32B）
  - 必选（CLI 方式）：Python 3.10.x（强烈推荐 3.10，其他版本可能依赖报错）
  - 可选：Chrome 浏览器（网页自动化功能需要）
- 🌐 **网络**：用本地模型完全不需要联网。首次下载 Docker 镜像可能需要联网（但你可以提前下载好）。用云端 API 需要联网

## 配合什么软件

- **Docker**：Docker 方式是官方推荐的安装方式，最简单
- **Ollama**：最常用的本地模型运行工具，装好 Ollama 后 AgenticSeek 能自动调用
- **LM Studio**：另一个本地模型运行工具，图形界面更友好
- **Git**：克隆仓库、更新版本用
- **浏览器**：AgenticSeek 能自己控制 Chrome 浏览器做自动化任务（需要 ChromeDriver 版本严格匹配）
- **Python**：CLI 模式依赖 Python 3.10.x

## 客观评价

**优点**：
- 完全本地化、完全私密，数据不出本机，对数据安全有要求的用户（企业开发者、研究人员）是刚需
- 真正能自主干活——不是"给建议"而是"自己动手"，包括打开网页、搜索、写代码、运行、调试
- 支持语音交互（虽然目前只支持英语），有"钢铁侠 Jarvis"的感觉
- 开源免费（MIT 许可证），代码完全透明
- 支持多种本地模型（Ollama、LM Studio、自托管服务器）
- 有"隐身浏览"功能，降低被反爬虫检测的概率

**缺点/坑**：
- 硬件门槛高！需要高端显卡（24GB+ 显存推荐），普通电脑跑不起来或者效果很差（7B 模型效果很差，容易幻觉）
- 早期原型阶段，Agent 路由系统不稳定，可能分配错误的 Agent 来处理任务
- 语音功能局限——只支持 CLI 模式，且只支持英语输入
- 网页表单自动填写功能还是实验性的，可能失败
- 提示词优化针对 Deepseek 等推理模型，用 GPT-4o 等其他模型效果可能不好
- Docker 首次启动很慢（要下载镜像），后端需要 5 分钟才能就绪，新手容易被吓到以为装失败了
- ChromeDriver 版本敏感，浏览器自动化需要严格匹配 Chrome 和 ChromeDriver 版本，配置麻烦
- 作者明确说这是零资金副业项目，没有路线图、没有固定更新，未来发展不确定
- 需要显式指令——必须明确说"做网页搜索"，不能模糊提问，否则它可能不理解你的意图

**适合谁**：对数据安全有严格要求的企业开发者、有高端显卡（24GB+ 显存）的个人开发者、想要"真正本地化 AI"的极客。

**不适合谁**：没有高端显卡的普通用户（本地模型效果会很差）、希望"开箱即用不用配置"的用户（这个项目需要不少配置）、需要稳定商业支持的用户（这是零资金副业项目）。

**评分**：7/10 — 完全本地化是独门绝技，但硬件门槛高、成熟度低，只适合特定人群

## 未来趋势

- 📈 **所处阶段**：早期原型阶段。功能能用但不够稳定，适合极客尝鲜，不适合生产环境
- 🔮 **6-12 个月走向**：如果作者能找到资金或更多贡献者，可能会加入更多模型支持、改进 Agent 路由系统、完善语音功能。但也有可能作者因为精力有限而放缓更新（零资金副业项目的通病）。本地模型会越来越强（Deepseek、Magistral 等在快速进步），这会让 AgenticSeek 的能力跟着提升
- ⭐ **关注度**：3/5 — 概念很好（完全本地化），但硬件门槛和成熟度限制了受众，适合特定人群关注
