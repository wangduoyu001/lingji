## 干什么

CrewAI 是一个让多个 AI 代理协作完成复杂任务的框架。你可以把它理解成"AI 团队管理系统"——你不是只雇一个 AI 员工，而是组建一个 AI 团队，每个 AI 有各自的专长和角色，它们互相配合完成一个大项目。比如做一个"市场分析报告"，你可以让一个 AI 负责搜集数据、一个 AI 负责分析数据、一个 AI 负责写报告、一个 AI 负责校对，最后它们合力产出一份完整报告。

它和 AutoGPT 的区别是：AutoGPT 是一个 AI 代理自己分解任务、自己执行；CrewAI 是多个 AI 代理各自有专长、互相配合。和 ElizaOS 的区别是：ElizaOS 关注的是"AI 角色在社交平台上互动"，CrewAI 关注的是"多个 AI 代理协作完成工作流"。

它有两个核心概念：**Crews**（团队模式，多个代理协作）和 **Flows**（工作流模式，事件驱动、有条件分支）。你可以只用 Crews（适合简单的顺序任务），也可以把 Crews 嵌到 Flows 里（适合复杂的、有条件判断的流程）。整体来说，这是一个"把复杂任务拆给多个 AI 分工完成"的编排框架。

## 能实现什么效果

举个例子：你要做一个"竞品分析报告"，手工做要花 2-3 天（搜集竞品信息、整理成表格、分析优劣势、写报告）。用 CrewAI，你可以定义一个 4 人 AI 团队：研究员（负责搜集信息）、分析师（负责整理和分析数据）、写手（负责写报告）、校对员（负责检查错误）。运行之后，它们自动配合：研究员先搜集 → 交给分析师整理 → 交给写手写报告 → 交给校对员检查 → 输出最终报告。时间可能从 2-3 天缩短到 30 分钟，而且格式统一、不会漏掉关键点。

另一个例子：你是做投资的，每天要分析多只股票的舆情和财务数据。用 CrewAI，你可以定义一个自动化流程：数据抓取代理（每天自动爬新闻和财报）→ 情感分析代理（分析新闻是正面还是负面）→ 财务分析代理（计算关键指标）→ 报告代理（生成每日摘要发你邮箱）。设好之后，之后每天自动跑，你早上打开邮箱就能看到昨天的分析报告。相当于雇了一个 24 小时不休息的研究助理团队。

它还能帮你做"内容生产流水线"——比如你运营一个科技博客，需要每天发一篇深度文章。定义一个 Crew：选题代理（从热门话题里选题）→ 资料搜集代理（找相关论文和新闻）→ 写作代理（写初稿）→ 编辑代理（润色和加配图）→ 发布代理（发到博客和社交媒体）。一条龙自动化，你只需要偶尔看一下最终产出质量。

## 怎么用

- **想快速试试**：先确保有 Python 3.10-3.13 和 uv（推荐用 uv 管理 Python 包，比 pip 快）→ 运行 `uv pip install crewai` 安装 → 运行 `crewai create crew my_project` 创建一个新项目 → `cd my_project && crewai install` 安装依赖
- **想定义 AI 团队**：打开项目里的 `src/my_project/config/agents.yaml` → 定义每个 AI 代理的角色、目标、背景故事（比如"你是一个资深数据分析师，擅长从杂乱数据里找规律"）→ 保存
- **想定义任务流程**：打开 `src/my_project/config/tasks.yaml` → 定义每个任务的描述、期望输出、由哪个代理执行 → 保存
- **想运行**：运行 `crewai run` → 看 AI 团队开始协作 → 等它们跑完，查看输出结果
- **想做复杂工作流（带条件判断）**：用 Flows 功能，在代码里用 `@start`、`@listen`、`@router` 等装饰器定义事件驱动流程 → 可以做什么"如果分析结果是正面就买入、负面就卖出"这种有条件分支的逻辑

## 运行位置

- 🖥️ **本机**：Windows、Mac、Linux 都可以，需要 Python 3.10-3.13。装完之后在终端里运行，也可以在 VS Code 里开发和调试
- ☁️ **服务器**：可以部署到任何支持 Python 的服务器或云平台（AWS、GCP、Azure 等）。适合需要定时运行或持续运行的场景
- 📓 **Jupyter Notebook**：支持在 Notebook 里交互式开发，适合原型设计和调试
- 🌐 **没有网页界面**：CrewAI 是纯代码框架，没有像 AutoGPT 平台那样的拖拽式网页界面。需要用代码定义一切（企业版可能有更多界面功能）

## 需要准备什么

- 💰 **要钱吗**：开源版免费（社区版）。企业版（CrewAI AMP Suite）是付费的，有统一控制平面、高级安全保障、7x24 支持等。开源版够个人和小型团队用了
- 🔑 **API Key**：默认需要 OpenAI API Key（因为默认用 OpenAI 的模型）。把 Key 写到 `.env` 文件里的 `OPENAI_API_KEY` 字段。也支持其他模型（通过 Ollama 跑本地模型、或用其他云端模型），但需要额外配置
- 💻 **电脑配置**：能跑 Python 的电脑都行。如果要用本地模型，需要好一点的显卡。跑多个 AI 代理同时调用 API 对电脑配置要求不高，主要是 API 费用
- 📦 **要装什么**：Python 3.10-3.13、uv（推荐）或 pip。安装命令：`uv pip install crewai`。如果需要用可选工具（比如搜索），装 `uv pip install 'crewai[tools]'`
- 🌐 **网络**：需要能访问 OpenAI API（或其他你用的模型的 API）。如果在国内，可能需要代理。用本地模型可以不用联网

## 配合什么软件

- **Python**：核心，整个框架基于 Python
- **VS Code / PyCharm**：推荐用，写和调试 CrewAI 项目
- **Jupyter Notebook**：适合交互式开发和测试
- **LangChain（可选）**：CrewAI 是独立于 LangChain 的，但可以和 LangChain 的工具集成
- **Ollama / LM Studio**：如果想用本地模型、不付 API 费用，需要这些工具
- **Git**：推荐用，管理代码版本

## 客观评价

**优点**：
- 设计很清晰——"多个 AI 代理协作"这个模型很符合人对"团队工作"的理解，容易设计和调试
- 支持两种模式：Crews（简单顺序协作）和 Flows（复杂事件驱动），灵活度高，既能做简单任务也能做复杂流程
- 完全独立于 LangChain，没有 LangChain 的笨重和黑魔法，代码更容易理解和调试
- 有 YAML 配置文件，可以不用写太多代码就能定义代理和任务，对新手友好
- 社区活跃，有很多教程和示例项目，遇到问题容易找到参考
- 支持本地模型，可以用 Ollama 等工具跑开源模型，不用付 API 费用

**缺点/坑**：
- 需要写代码，没有网页界面（和 AutoGPT 平台比）。不适合完全不懂编程的人
- 默认用 OpenAI API，如果不想付 API 费用需要额外配置本地模型，增加复杂度
- 多个 AI 代理协作，如果任务定义不清晰，可能会出现代理之间"配合不好"的情况（比如一个代理的输出格式不符合下一个代理的期望）
- 调试多个代理协作的流程比调试单个脚本复杂，需要仔细设计每个代理的输入输出
- 如果代理数量多、任务复杂，API 调用次数会很多，费用可能不低（可以用本地模型缓解）

**适合谁**：有 Python 基础、想做多步骤 AI 自动化流程的人、想研究多代理协作的人、想搭建 AI 工作流的人。不适合完全不懂编程的人。

**不适合谁**：只想用一个 AI 助手完成简单任务的人（用 Open Interpreter 或 Hermes Agent 更合适）、不想写代码的人、对 API 费用敏感且不想搞本地模型的人。

**评分**：8/10 — 多代理协作领域做得最好的框架之一，设计清晰、文档完善。扣分的点是缺少网页界面（对新手不够友好）和默认依赖 OpenAI API。
