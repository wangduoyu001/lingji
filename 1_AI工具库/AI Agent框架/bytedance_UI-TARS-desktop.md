# UI-TARS Desktop — 字节跳动的 AI 替你操作电脑

> ⭐ 36,975 | 📅 2026-06-20 | [GitHub](https://github.com/bytedance/UI-TARS-desktop)

## 干什么

UI-TARS 是字节跳动做的"AI 替你操作电脑"工具。它不是聊天机器人，而是个能看屏幕、会点鼠标、会敲键盘的 AI Agent。你跟它说"帮我在飞猪上订一张明天去北京的机票"，它会自己打开浏览器 → 搜索航班 → 比较价格 → 填信息 → 下单——就像有个人坐在你电脑前帮你干活一样。

它的核心能力是"视觉理解"——不需要网站提供 API，它直接看屏幕上的按钮、文字、图片，像人一样理解界面上有什么、在哪里、该怎么操作。这意味着任何你能在电脑上手动做的事情，理论上它都能做。

底层的 UI-TARS 模型是字节跳动自己训练的视觉语言模型，专为"理解和操作电脑界面"优化。项目还包含 Agent TARS——一个更通用的 CLI 版本，支持命令行和 Web UI 两种交互方式。

## 能实现什么效果

用了 UI-TARS 之后，你不需要再一个个网页去手动操作。想订机票？一句话。想批量下载图片？一句话。想帮你在 VS Code 里打开自动保存？一句话。

对于一个日常需要大量在线操作的人来说（比如做电商的要每天登录各个平台看数据、做调研的要每天翻几十个网站找信息），这种工具能省下大量重复性的"点击-输入-等待"时间。

实测案例：让 UI-TARS 在 booking.com 上预订酒店并生成交通指南、用 Priceline 预订航班、在 VS Code 里切换设置、查看 GitHub Issue——这些都可以通过自然语言指令完成。

## 怎么用

- **桌面 App**：下载安装 → 打开 → 输入你要做的事情 → 看着它操作。支持 macOS 和 Windows。
- **Agent TARS CLI**（更灵活）：`npx @agent-tars/cli@latest` 一行命令启动 → Web UI 或命令行交互。
- **指定模型**：`agent-tars --provider anthropic --model claude-3-7-sonnet-latest --apiKey your-key`。
- **典型指令示例**："帮我在浏览器里打开淘宝，搜索'机械键盘'，找到销量最高的前三个，把截图保存下来"→ Agent 会自动完成。
- **连接 MCP**：Agent TARS 支持 MCP 协议，可以挂载额外的工具扩展能力。

## 运行位置

- **桌面 App**：macOS / Windows
- **Agent TARS CLI**：macOS / Linux / Windows（需要 Node.js ≥ 22）
- **浏览器模式**：通过 Web UI 控制

## 需要准备什么

- 免费开源（Apache 2.0 协议）
- UI-TARS Desktop：需要下载安装包，不需要 API Key（用本地模型）
- Agent TARS CLI：需要模型 API Key（支持火山引擎（豆包）、Anthropic（Claude）等多种提供商）
- 电脑配置：Desktop 版需要一定算力跑本地模型；CLI 版普通电脑就行（推理在云端）
- Node.js ≥ 22（如果用 CLI 版）

## 配合什么软件

- 独立使用即可操作电脑上的任何软件
- 可直接操作浏览器（Chrome / Edge 等）
- 可选配合 MCP Servers 扩展能力
- 和 VS Code、GitHub 等开发工具天然兼容

## 客观评价

**优点**：大厂出品（字节跳动），技术实力有保障；视觉理解 + 自然语言控制的思路很先进——不需要 API，只要能"看"就能操作；CLI 版支持多模型提供商，选择灵活；Apache 2.0 协议友好。

**缺点**：目前还在早期阶段，操作复杂界面的成功率不算高（容易点错、走丢）；Desktop 版本地运行需要不低的算力；中文场景下的一些特定网站（如淘宝、京东）兼容性还需优化；操作速度比人慢（毕竟要一步步识别、思考、执行）。

**适合谁**：想自动化日常电脑操作的人、需要批量处理网页操作的运营人员、对 AI Agent 电脑操控感兴趣的研究者。**不适合**：追求极高操作精度的场景（目前成功率还不够高）、完全没有技术基础的小白。

**评分 6/10**：方向非常正确，但成熟度还远不够。这个赛道是 2026 年最热的方向之一，值得持续关注。
