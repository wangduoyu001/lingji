## 干什么

Hermes Agent 是由 Nous Research（做 Hermes 大模型的那家公司）开发的自改进 AI 代理。它最大的特点是"会学习"——不像其他 AI 助手你问一句它答一句、下次对话就不记得上次了，Hermes Agent 会在完成任务后自己总结"刚才这个任务我是怎么完成的"，把方法存成"技能"（Skill），下次遇到类似任务直接调用，不用重新开始。你可以把它理解成"一个会积累经验的 AI 员工"——用得越久，它越懂你的习惯和需求。

它还有一个很实用的功能：支持通过 Telegram、Discord、Slack、WhatsApp、Signal 等聊天软件来远程操作。比如你不在电脑旁边，但想让 AI 帮你跑个任务，直接在 Telegram 上发消息给它，它就在服务器上开始干活，干完了发结果给你。相当于你的 AI 助理随身带着，不用坐在电脑前才能用。

它完全开源（MIT 许可证），可以用任何大模型（OpenAI、Anthropic、Google、本地模型都行），不绑定某一家公司的 API。如果你不想付钱给大模型公司，可以接本地跑的开源模型（通过 Ollama 等工具），这样用多少都不花钱。

## 能实现什么效果

举个例子：你经常需要"每周五下午生成本周的工作总结"。第一次，你告诉 Hermes Agent"帮我生成本周工作总结，从我的日历和邮件里提取关键信息"，它执行完后自己创建一个"生成周报"的技能。下周你再说"生成本周工作总结"，它直接调用上次创建的技能，不用你再解释一遍要怎么做。用得越久，它积累的技能越多，你要做的解释越来越少，最后可能只需要说"照上周那样"它就懂了。

另一个例子：你经常需要"监控某个关键词在社交媒体上的讨论"。用 Hermes Agent，你可以设置一个定时任务（内置 cron 调度器），每天自动搜索、整理成报告发你 Telegram。你不用每天手动去查，AI 自动帮你盯着。如果有重要信息，它还能主动发消息提醒你，相当于雇了一个 24 小时不休息的情报收集员。

它还能帮你做"跨平台消息整合"——比如你在 Telegram、Discord、Slack 上都加了它，无论在哪个平台发消息，它都知道上下文（通过记忆系统）。你在 Telegram 上问了"帮我查一下 X 项目的进度"，第二天在 Discord 上问"X 项目怎么样了"，它知道你说的就是昨天那个 X 项目，不用你重复解释。相当于一个统一的 AI 助理，在各个平台上都能用。

## 怎么用

- **想快速安装（Linux/macOS/WSL2）**：在终端里运行 `curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash` → 装完运行 `source ~/.bashrc` 重新加载 → 输入 `hermes` 启动
- **Windows 用户**：在 PowerShell 里运行 `iex (irm https://hermes-agent.nousresearch.com/install.ps1)` → 装完输入 `hermes` 启动
- **想配置大模型**：运行 `hermes model` → 选择你想用的模型（OpenAI/Anthropic/本地模型都行）→ 如果要用的模型需要 API Key，按提示输入
- **想通过 Telegram 等平台远程用**：运行 `hermes gateway` → 按提示连接你想要的平台（Telegram/Discord/Slack 等）→ 之后在那些平台上发消息就能操作 AI
- **想让 AI 自己学习（创建技能）**：正常使用，完成复杂任务后 AI 会自动问你要不要保存成技能 → 选"是" → 下次类似任务直接调用。也可以手动管理技能

## 运行位置

- 🖥️ **本机**：Windows（原生 PowerShell 支持）、Mac、Linux、WSL2、Termux（安卓上的 Linux 环境）都支持。装完之后在终端里运行
- ☁️ **服务器**：可以部署到 $5/月的 VPS（虚拟私有服务器），之后不用开本机也能用（通过 Telegram 等平台远程操作）。也支持 Serverless 部署（Modal/Daytona），空闲时不计费，按需唤醒
- 📱 **手机**：通过 Telegram、Discord、Slack、WhatsApp、Signal 等平台操作，相当于手机上也能用。没有独立的手机 App，但聊天软件本身就是界面
- 🐳 **Docker**：支持 Docker 作为终端后端，可以跑在容器里

## 需要准备什么

- 💰 **要钱吗**：开源版免费（MIT 许可证）。运行成本是大模型 API 费用（如果你用云端模型）或服务器费用（如果你部署到 VPS）。如果用本地模型 + 本机运行，可以完全免费
- 🔑 **API Key**：取决于你用的模型。如果用 OpenAI/Anthropic/Google 的模型，需要对应 API Key。如果用本地模型（Ollama 等），不需要 API Key。推荐用 Nous Portal（Nous Research 自己的模型服务），一个订阅覆盖所有工具，不用分别搞多个 API Key
- 💻 **电脑配置**：要求不高。安装器会自动装好依赖（Python 3.11、Node.js、ripgrep、ffmpeg）。如果用本地模型，需要好一点的显卡
- 📦 **要装什么**：安装脚本会自动装好所有依赖。如果没有 Git，会自动下载一个便携版（MinGit，约 45MB），不用管理员权限
- 🌐 **网络**：需要能访问你用的模型的 API。如果用本地模型，不用联网。Nous Portal 需要联网

## 配合什么软件

- **终端（命令行）**：主要交互方式，有完整的 TUI（终端用户界面），支持多行编辑、命令补全、对话历史
- **Telegram / Discord / Slack / WhatsApp / Signal**：消息平台，装完 gateway 之后可以在这些平台上操作 AI
- **Ollama / 本地模型工具**：如果想不付 API 费用、用本地模型
- **Docker**：可选，用 Docker 作为终端后端
- **Nous Portal**：推荐，Nous Research 的模型服务，300+ 模型、一个订阅、覆盖所有工具（网页搜索、图像生成、TTS、云浏览器等）

## 客观评价

**优点**：
- 真正的"自改进"——会积累技能、跨会话记住你的习惯，用得越久越好用。这是大部分 AI 助手没有的
- 支持的平台多（6 种终端后端、6 种消息平台），部署灵活，本机/服务器/Serverless 都能跑
- 完全开源、MIT 许可证，可以随便改、随便用
- 支持任何大模型，不绑定某一家，可以用本地模型完全免费跑
- 有内置 cron 调度器，可以设置定时任务，不用借助外部工具
- 40+ 内置工具，开箱即用

**缺点/坑**：
- 需要写命令/用终端，没有网页界面（虽然可以通过消息平台操作，但配置还是需要终端）。不适合完全不懂命令行的人
- "自改进"功能虽然酷，但也可能出问题——如果 AI 自己创建的技能有 bug，可能会导致后续任务出错，需要手动检查和管理技能
- 记忆系统和技能系统需要时间积累，刚装好的时候和普通 AI 助手区别不大，需要用到一定程度才能体现出优势
- 文档虽然详细，但有些高级功能（比如自定义终端后端、MCP 集成）需要一定技术背景才能搞定
- 如果用 Nous Portal 以外的模型，需要自己管理多个 API Key，有点麻烦

**适合谁**：想要一个"会越来越懂你"的 AI 助理的人、需要远程操作 AI 的人（通过 Telegram 等）、有技术背景的人。不适合完全不懂技术也不想学的人。

**不适合谁**：想要开箱即用、完全不用配置的人（云版 Claude/ChatGPT 更适合）、对命令行有强烈排斥的人、不需要"自改进"功能的人（如果只是偶尔用 AI，积累技能的优势体现不出来）。

**评分**：7.5/10 — "自改进"是独特优势，多平台支持也很实用。扣分的点是缺少网页界面和对新手的门槛。
