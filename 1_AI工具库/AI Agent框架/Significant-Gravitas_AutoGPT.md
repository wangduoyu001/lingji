## 干什么

AutoGPT 是一个能让你创建、部署和管理持续运行 AI 代理的平台。你可以把它理解成"AI 员工的招聘和培训系统"——你告诉它要完成什么目标，它会自己把大目标拆成小任务、逐个执行、检查结果，全程基本不用你盯着。它最早把"给 AI 一个目标，它自己干活"这个想法变成了现实，所以在 AI 代理圈子里算是鼻祖级项目。

它现在有两个主要部分：一个是**新平台**（AutoGPT Platform），带网页界面，可以像搭积木一样拖拽组件来组装 AI 工作流；另一个是**经典版**（AutoGPT Classic），更适合开发者自己写代码定制。平台版对新手友好，经典版对程序员友好。

这个项目最厉害的地方是"持续运行"——不像 ChatGPT 你问一句它答一句，AutoGPT 的代理可以在服务器上一直跑，定期自己检查进度、调整策略，有点像你雇了一个不用睡觉的远程员工。

## 能实现什么效果

举个例子：你想做一个"每天自动刷 Reddit 热门话题，然后生成短视频发到 TikTok"的自动化流程。用 AutoGPT 平台，你可以在网页上拖拽几个模块（读取 Reddit → 识别热门 → 生成脚本 → 生成视频 → 发布），点一下运行，之后它每天自动帮你干这个活。你只需要偶尔看看数据，不用自己动手。

另一个例子：你有 YouTube 频道，每次发视频后要手动提取金句发社交媒体。用 AutoGPT，你可以设置一个代理，订阅你的频道，新视频一发布就自动转录、提取金句、生成社媒文案、定时发布。相当于雇了一个 24 小时不休息的内容运营。

它还能帮你做"研究助理"——比如设置一个代理，每天自动搜索你关注领域的最新论文、整理摘要、发到你的邮箱或 Discord。省下的时间可能是每天 1-2 小时的人工，变成设好之后就不用管。

## 怎么用

- **想快速试试**：去[云版等待名单](https://bit.ly/3ZDijAI)排队（目前是内测，公测快了）→ 不用自己装东西 → 直接用网页界面操作
- **想自己部署（技术向）**：确保电脑有 Docker → 跑一键安装脚本（`curl -fsSL https://setup.agpt.co/install.sh -o install.sh && bash install.sh`）→ 装完打开网页界面 → 拖拽模块组装代理
- **想从头写代码定制**：克隆代码库 → 用 Forge 工具包快速搭建自己的代理应用 → 用 Benchmark 测试性能 → 用前端界面控制和监控
- **想直接用现成的代理**：打开平台的市场（Marketplace）→ 找别人已经做好的代理 → 点一下就能部署运行
- **想监控代理运行**：平台有内置的监控和分析页面 → 实时看代理在执行什么、成功率多少、哪里卡住了

## 运行位置

- 🖥️ **本机**：Windows（需要 WSL2）、Mac、Linux 都可以，用 Docker 跑。要求 4 核 CPU、16GB 内存推荐、10GB 硬盘空间
- ☁️ **服务器**：可以部署到云服务器，代理可以持续运行不用本机开机
- 🌐 **网页界面**：部署完之后有本地网页界面，在浏览器里操作，不用写代码
- 📱 **手机**：目前没有官方手机 App，但可以通过浏览器访问网页界面来查看代理状态

## 需要准备什么

- 💰 **要钱吗**：自己部署免费（开源），云版目前内测免费，公测后可能有付费计划。自己部署需要服务器费用（如果用云服务器的话）
- 🔑 **API Key**：需要大模型 API Key（OpenAI、Anthropic 等），按使用量付费。如果自己有服务器，也可以接本地跑的开源模型
- 💻 **电脑配置**：自己部署的话，推荐 4 核 CPU + 16GB 内存。如果只是用云版，普通电脑能上网就行
- 📦 **要装什么**：Docker Engine 20.10+ 和 Docker Compose 2.0+（一键脚本会自动装）。Windows 用户需要先装 WSL2
- 🌐 **网络**：需要能访问 GitHub 和 Docker Hub 来下载镜像。如果需要用 OpenAI 等国外 API，可能需要代理

## 配合什么软件

- **Docker**：必须，整个平台跑在 Docker 容器里
- **VS Code**：推荐用，官方教程用 VS Code 作为代码编辑器
- **Git**：必须，用来克隆代码库
- **Node.js**：需要 16.x 以上，前端界面用
- **自己开发的系统**：可以通过 API 触发代理运行，也可以让代理把结果发到你的系统

## 客观评价

**优点**：
- AI 代理领域的鼻祖，社区大、教程多、遇到问题容易找到答案
- 平台版有网页界面，拖拽就能搭工作流，不用写代码
- 有市场（Marketplace），可以直接用别人做好的代理，不用自己从零搭
- 支持持续运行，代理可以在服务器上 7x24 小时跑，不用本机一直开机
- 开源（MIT 许可证，平台部分用 Polyform Shield），代码透明

**缺点/坑**：
- 自己部署有点技术门槛，需要懂 Docker 和基本命令行操作
- 云版还在内测，公测时间没确定，想用托管版可能还要等
- 运行代理需要大模型 API，如果用贵的模型（GPT-4 级别）成本可能不低
- 项目在转型期——从经典版转向新平台，有些老文档可能过时，新手容易懵
- 代理跑起来之后如果逻辑有问题，可能会一直烧 API 费用直到你发现并关掉

**适合谁**：想做 AI 自动化工作流的人、有服务器资源的技术爱好者、想研究 AI 代理怎么搭的人。不适合完全不懂技术也不想学的人（等云版出来可能会好一些）。

**不适合谁**：只想在本地跑一个简单的 AI 助手的人（用 Open Interpreter 或 Hermes Agent 更合适）、不想折腾部署的人、对 API 费用敏感的人。

**评分**：7/10 — 概念领先、功能全面，但部署复杂度和成本控制扣分。云版出来后可能会涨到 8-9 分。
