## 干什么

Langflow 像一个"AI 乐高积木台"——你不需要写代码，把一个个 AI 功能模块（比如"调用大模型""搜索知识库""执行代码"）像搭积木一样拖出来、连上线，就能搭出一个能自动干活的 AI 应用。

没它之前，你想让 AI 自动处理一些事情（比如"收到客户邮件后自动分类并回复"），得找程序员写代码、搭服务器、调试半天。有了 Langflow，你打开浏览器，拖几个方块、连几根线，10 分钟就能搞定一个能用的 AI 工作流。

它底层支持几乎所有主流大模型（OpenAI、Claude、Gemini、DeepSeek 等），还内置了向量数据库、代码执行器、MCP 协议等工具，等于把"造 AI 应用需要的所有零件"都打包进了一个画布里。

## 能实现什么效果

用 Langflow 搭出来的东西可以像普通软件一样对外服务——搭完一个"智能客服"工作流，它能 7×24 小时自动回复客户问题；搭完一个"文档分析"工作流，扔给它 500 页 PDF，它能逐页分析并生成摘要报告。

最厉害的是，搭好的工作流可以一键变成 API 接口，也就是说你把这个工作流变成一个"网址"，别的软件可以通过访问这个网址来调用它。还支持导出成 MCP Server，让 Claude Code、Codex 这类 AI 编程工具直接调用。

对于不会写代码的人来说，这意味着你也能"造软件"了——只不过你造的软件是用 AI 驱动的。相比找程序员开发一个内部工具动辄几万块，Langflow 让你自己就能搭出来，省下的不只是钱，更是来回沟通需求的时间。

## 怎么用

- **搭一个自动客服**：拖一个"接收消息"模块 → 连到"大模型问答"模块 → 再连到"知识库检索"模块 → 最后连"发送回复"，你的客服就上线了。
- **做一个文档分析器**：把 PDF 拖进去 → Langflow 自动拆分段落 → 逐段发给大模型分析 → 汇总成表格或报告，一键导出。
- **建一个内容审核流水线**：文章进来 → 先过"敏感词检测" → 再过"大模型审核" → 最后标记"通过/拒绝"，全自动。
- **搭一个数据查询助手**：连接你的数据库 → 用自然语言问"上月销售额最高的产品是什么" → 自动转成 SQL → 执行 → 返回图表。
- **做一个 MCP 工具**：把工作流导出成 MCP Server → 在 Claude Code 里直接用 `/` 命令调用，等于给你的 AI 编程助手加了自定义超能力。

## 运行位置

- **Langflow Desktop**：Windows 和 macOS 桌面应用，下载双击就能用，自带所有依赖
- **本地 Python 安装**：一条命令 `uv pip install langflow` 就能跑，打开浏览器访问 http://127.0.0.1:7860
- **Docker**：`docker run` 一行命令启动，适合有 Docker 的用户
- **云端部署**：可以部署到 Vercel、Railway、AWS 等平台，生成公网可访问的链接

## 需要准备什么

- 免费开源（MIT 协议），代码可以随便用、随便改，商用也没问题
- 不需要注册账号就能本地运行
- 需要至少一个大模型的 API Key（比如 OpenAI、Claude 或 DeepSeek 的 Key，获取方式：去对应官网注册，充值几十块就够用很久）
- 电脑配置：普通的笔记本电脑就能跑（4 核 CPU、8GB 内存够了），但如果要本地跑大模型则需要好显卡
- 需要 Python 3.10-3.14（如果用 pip 安装方式）或什么都不需要（如果用 Desktop 版）
- 如果要部署到云端，需要对应云平台的账号（如 Vercel 免费额度就够用）

## 配合什么软件

- 独立使用就能完成大部分工作
- 如果想用本地大模型：配合 Ollama 使用（先装 Ollama，再在 Langflow 里选 Ollama 作为模型来源）
- 如果想用到更多数据源：可以配合 Notion、Google Drive、GitHub 等（通过内置的连接器）
- 如果想监控工作流运行情况：配合 LangSmith 或 LangFuse（可选）

## 客观评价

**优点**：上手极快，拖拽式操作几乎没有学习成本；内置组件非常丰富，从大模型到数据库到代码执行全覆盖；社区活跃（14 万+ star、9000+ fork），遇到问题很容易搜到解决方案；支持导出 API 和 MCP Server，做完的东西可以真正"用起来"而不只是玩具。

**缺点**：复杂工作流（几十个节点以上）的可维护性会下降，调试起来比较费劲；文档虽然是英文为主，中文资料相对较少；免费版功能完整但云端部署要自己搞定服务器；某些高级功能（如企业级权限管理）需要付费版。

**适合谁**：想做 AI 自动化但不会写代码的人、想快速验证 AI 产品想法的创业者、需要搭内部 AI 工具的小团队。**不适合**：需要极高定制化的大型企业系统、对延迟要求极其苛刻的实时应用。

**评分 8/10**：同类型工具里做得最成熟的，体验流畅，生态完善。扣分主要是复杂场景下的维护成本和中文支持还不够好。

## 未来趋势

项目处于**快速增长期**，2023 年 2 月创建至今积累了 15 万 star。随着 AI Agent 从概念走向生产，可视化 Agent 构建工具的需求会越来越大。

6-12 个月内：预计会加强多 Agent 协作能力、增强 MCP 生态集成、推出更多企业级功能。和 Dify 会形成双雄格局（Dify 偏重应用层，Langflow 偏重工作流引擎层）。

**关注度 4/5**：不是因为技术多颠覆，而是因为它解决了"让普通人也能造 AI 应用"这个巨大的市场痛点。
