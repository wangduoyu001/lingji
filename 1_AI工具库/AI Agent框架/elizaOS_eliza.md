## 干什么

ElizaOS 是一个开源的 AI 角色/代理开发框架。你可以把它理解成"给 AI 捏人设、然后让它去各个社交平台自动干活的工具"——比如你想做一个 AI 客服，它 24 小时在 Discord 和 Telegram 上回答用户问题；或者想做一个 AI 主播，在 Twitter 上自动发内容、和粉丝互动。它提供了一整套工具，让你可以创建、部署和管理这些 AI 角色。

它和 AutoGPT 不一样——AutoGPT 关注的是"给目标→自动执行任务"，ElizaOS 关注的是"创造一个有个性的 AI 角色→让它在各个平台上和人互动"。你可以给 AI 角色设置背景故事、性格、专长领域，然后它会用这个"人设"去和别人聊天、回答问题、发帖子。

它还有一个现代化的网页仪表盘（Web UI），你可以在浏览器里管理你的 AI 角色、查看对话记录、调整设置，不用全靠命令行。整体来说，这是一个"做 AI 角色并部署到社交平台"的一站式平台。

## 能实现什么效果

举个例子：你有一个 Discord 社群，每天有一堆人问重复的问题（比如"怎么安装？""XX 功能在哪？"）。用 ElizaOS，你可以创建一个 AI 角色，把它的"人设"设成"热心的社区助理"，把常见问题的答案喂给它，然后把它部署到 Discord 服务器上。之后它自动回答这些问题，你只需要偶尔检查一下它有没有答错。省下的时间可能是每天 1-2 小时的人工客服时间。

另一个例子：你想做一个"AI 推特机器人"，每天自动发和行业相关的内容、回复粉丝提问、转发优质内容。用 ElizaOS，你可以创建一个 AI 角色，连接你的 Twitter 账号，设置它的发帖频率和内容方向，然后它自动帮你运营。相当于雇了一个 24 小时不休息的社交媒体运营，而且还不会辞职。

它还能帮你做"多平台同步的 AI 客服"——同一个 AI 角色，可以同时接入 Discord、Telegram、Twitter，用户在哪个平台问问题，它都能回答，而且知道之前在其他平台的对话历史（通过记忆系统）。不用在每个平台都手动回复，效率提升可能是 3-5 倍。

## 怎么用

- **想快速搭一个 AI 角色（推荐）**：先装好 Node.js v24+ 和 bun → 运行 `bun add -g elizaos@beta` 安装 CLI → 运行 `elizaos create my-first-agent --template project` 创建项目 → `cd my-first-agent && bun install` → `bun run dev` 启动，打开网页界面操作
- **想接入社交平台**：在网页仪表盘里找到"连接器"（Connectors）→ 选择要接入的平台（Discord/Telegram/Twitter 等）→ 按提示授权 → AI 角色自动开始在那个平台上活动
- **想定制 AI 角色的"人设"**：在项目里找到角色配置文件 → 修改背景故事、性格、专长 → 重启代理 → 新的"人设"生效
- **想扩展功能（加插件）**：去 [plugins.elizacloud.ai](https://plugins.elizacloud.ai) 找社区插件 → 按文档安装 → 插件会给你的 AI 角色加新能力（比如"能查天气""能搜网页"）
- **想在本机测试不和真平台连接**：用内置的 REPL 聊天模式（`bun run packages/examples/chat/chat.ts`）→ 在终端里和 AI 角色对话 → 调试好了再部署到真实平台

## 运行位置

- 🖥️ **本机**：需要 Node.js v24+ 和 bun。Windows 用户需要用 WSL 2（因为某些依赖在原生 Windows 上可能有问题）。Mac 和 Linux 直接装就能用
- ☁️ **服务器**：可以部署到任何支持 Node.js 的服务器（Vercel、Cloudflare、AWS、GCP 都行）。文档里有部署到这些平台的教程
- 🌐 **网页界面**：部署完之后有本地网页仪表盘（默认在本机某个端口），在浏览器里管理 AI 角色
- 📱 **移动端**：没有官方 App，但可以通过浏览器访问网页仪表盘来查看状态。AI 角色本身在服务器上跑，和移动端无关

## 需要准备什么

- 💰 **要钱吗**：开源版免费（MIT 许可证）。如果需要部署到服务器，需要付服务器费用。AI 角色调用大模型 API 需要付 API 费用
- 🔑 **API Key**：需要一个大模型的 API Key（OpenAI、Anthropic、Gemini、Grok 等都支持）。把 Key 写到 `.env` 文件里的 `OPENAI_API_KEY` 或其他对应字段。也支持本地模型（通过 Ollama 等工具），这样就不用付 API 费用
- 💻 **电脑配置**：能跑 Node.js 和 bun 的电脑都行，配置要求不高。如果要跑本地模型，需要好一点的显卡
- 📦 **要装什么**：Node.js v24+（必须用 24 以上版本）、bun（包管理工具，比 npm 快）。Windows 用户需要先装 WSL 2。安装命令见上方"怎么用"
- 🌐 **网络**：需要能访问大模型 API（如果用云端模型）。如果用本地模型，不用联网也能跑

## 配合什么软件

- **Node.js 和 bun**：必须，整个框架基于它们
- **Discord / Telegram / Twitter 等社交平台**：AI 角色要部署到这些平台，需要这些平台的账号和 Bot Token
- **VS Code**：推荐用，写插件和定制角色的时候用
- **Docker**：可选，如果想用容器化部署
- **本地模型工具（Ollama 等）**：如果想不付 API 费用、用本地模型跑 AI 角色，需要装这些工具
- **独立运行**：核心框架是独立的，不强制依赖其他软件

## 客观评价

**优点**：
- 真正"全套"——从开发框架到网页界面到社交平台接入，一条龙，不用自己拼凑
- 支持的平台多（Discord、Telegram、Twitter、Farcaster、Bluesky 等），覆盖面广
- 插件系统完善，社区已经有一些现成的插件可以用，不用自己从零写
- 有记忆系统（RAG），AI 角色能"记住"之前和用户的对话，不会每次都像失忆了一样
- 开源、MIT 许可证，可以随便改、随便用，不用担心法律风险
- 30+ 个示例项目，覆盖各种使用场景，新手可以参考

**缺点/坑**：
- 技术要求不低——需要懂 Node.js、懂怎么配置社交平台 Bot、懂怎么管理 API Key。不完全是小白天花板
- Windows 支持不够好，需要用 WSL 2，对纯 Windows 用户不太友好
- 文档虽然多，但有些地方比较技术化，非程序员可能看不懂
- AI 角色在社交平台上活动，如果"人设"没调好，可能会说出不合适的话，需要仔细测试
- 调用大模型 API 需要持续付费，如果 AI 角色很活跃，每月 API 费用可能不低（可以用本地模型解决这个问题）

**适合谁**：想做 AI 客服/AI 社群助理的人、想做 AI 社交机器人的人、有 Node.js 开发经验的程序员。不适合完全不懂技术的人。

**不适合谁**：只想在本机和一个 AI 对话的人（用 ChatGPT 或 Claude 更简单）、不想付 API 费用也不想搞本地模型的人、对 Windows 原生支持有强需求的人。

**评分**：7.5/10 — 功能全面、开源免费，但技术门槛和 Windows 支持扣分。如果能接受用 WSL 2 或者在 Mac/Linux 上跑，这个分数可以到 8。
