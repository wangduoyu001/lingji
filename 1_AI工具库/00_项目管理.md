## 🏷 标记是什么意思

每个项目有 4 个标记，你只需要理解 2 个：

### 兴趣度（你有多想用）

| 数字 | 图标 | 意思 |
|------|------|------|
| `3` | 🔴 | **必须试** — 看着就想装 |
| `2` | 🟡 | **想试试** — 有空装一下 |
| `1` | 🟢 | **先看看** — 观望中 |
| `0` | ⚫ | **跳过** — 不适合我 |

### 使用状态（你现在用不用）

| 文字 | 意思 |
|------|------|
| `未试` | 还没装过 |
| `已安装` | 装好了 |
| `在用` | 天天用 |
| `已弃用` | 以前用，现在不用了 |
| `不合适` | 看了觉得没用 |

### 实用度（客观评分）

| 文字 | 意思 |
|------|------|
| `强烈推荐` | 闭眼装 |
| `可试` | 值得折腾 |
| `待评估` | 还没细看 |
| `不适合` | 放弃 |

## ✍️ 怎么改标记（3 步搞定）

**第 1 步**：点项目名字，打开项目页面。

**第 2 步**：页面最顶上，你会看到两排 `---` 包起来的内容，像这样：
```
---
title: "某个项目"
interest: 1          ← 改这个数字
status: 未试          ← 改这个文字
usable: 待评估        ← 改这个文字
---
```

**第 3 步**：改数字或文字，按 `Ctrl+S` 保存。

举个实际例子：
- 看到 [[项目/anthropics_claude-code|Claude Code]] 想试试 → 把 `interest: 1` 改成 `interest: 2`
- 已经装了 [[项目/CherryHQ_cherry-studio|Cherry Studio]] → 把 `status: 未试` 改成 `status: 在用`

## ❓ 常见问题

**Q：看不懂项目介绍怎么办？**
每个项目卡片有 6 个部分：干什么、怎么用、运行位置、需要准备什么、配合什么软件、未来趋势。看不懂词没关系，先看「干什么」和「怎么用」这两段，用的是大白话。

**Q：Stars 越多越好吗？**
Stars 是别人点的赞，一般越多越靠谱。但不绝对——有些小众工具虽然 stars 少，但正好解决你的问题。

**Q：装了不会用怎么办？**
每个项目卡片最底下有 GitHub 链接，点进去看原项目文档。或者告诉我项目名，我帮你找教程。

**Q：怎么把项目从列表里删掉？**
不需要删。把 `interest` 改成 `0`（⚫ 跳过），它就不会出现在前面的列表里了。
