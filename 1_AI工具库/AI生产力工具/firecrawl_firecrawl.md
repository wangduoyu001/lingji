# Firecrawl

> ⭐ 135,647 | 📅 2026-06-20 | [GitHub](https://github.com/firecrawl/firecrawl)
>
> 💡 **怎么标记**：改上面 `interest` 数字 → 3=必装 2=想试 1=观望 0=跳过 → 改完按 Ctrl+S 保存

## 干什么
Firecrawl 是给 AI 当"眼睛"的工具——把网页内容变成 AI 能读懂的干净文字（就像你请了个助理，专门帮你从乱七八糟的网页里整理出有用信息交给 AI）。没它之前，AI 看网页只能看到乱码和广告混在一起的一堆 HTML，根本没法理解。Firecrawl 会自动去掉广告、导航栏、弹窗这些垃圾，只保留正文，还能把 PDF、DOCX 这些文件也转成 AI 能用的格式。它还能让 AI 直接"操控"网页——搜索信息、点击按钮、填写表单，就像你雇了个上网助手。

## 能实现什么效果
用了 Firecrawl，你的 AI Agent 就变成了"能上网的 AI"。它可以自己去搜索竞品信息、抓取粉丝数据、采集行业报告，然后把结果整理好给你。对于做直播运营的你来说，可以用它批量抓取抖音/小红书上的对标账号主页信息、粉丝数据、热门内容，喂给 AI 去分析趋势。它覆盖 96% 的网页（包括需要 JavaScript 渲染的页面），自动处理反爬、代理轮换、限速等麻烦事，你不用懂任何爬虫技术。配合 Claude Code 或 WorkBuddy 的 MCP 接入，直接用自然语言就能指挥它上网干活。

## 怎么用
1. **AI 自动采集竞品数据**：Claude Code 接入 Firecrawl MCP → 说"帮我搜索抖音上命理类主播的粉丝数据" → AI 自动搜索+抓取+整理
2. **批量抓取网页内容**：提供一组 URL → Firecrawl 把所有页面转成 Markdown → 喂给 RAG 知识库做问答
3. **自动搜索并提取信息**：用 Agent 功能，只说需求（不需要提供 URL）→ AI 自己找到相关网页并提取内容
4. **模拟用户操作**：需要登录后才能看的页面 → Firecrawl 的 Interact 功能帮你点按钮、填表单、获取内容
5. **接入自动化平台**：Firecrawl + n8n → 定时自动抓取目标网站 → 数据自动存入数据库

## 运行位置
有两种使用方式：① 纯云端 SaaS（注册 firecrawl.dev 获取 API Key，直接调用，不需要安装任何东西）；② 自托管（用 Docker 在自己的服务器上部署，数据完全自控）。自托管版本需要 Linux 服务器和 Docker。

## 需要准备什么
① **云端版**：有免费额度（500 次抓取/月），超出后按量付费（约 $0.001/次），对个人使用来说免费额度够用。② 需要注册 firecrawl.dev 账号获取 API Key。③ 自托管版不需要 API Key，但需要一台 Linux 服务器（推荐 4GB 内存以上）。④ 不需要显卡。⑤ 自托管需要安装 Docker。⑥ Python/Node.js SDK 安装也很简单（pip install firecrawl-py 或 npm install firecrawl）。

## 配合什么软件
最佳搭配：Claude Code（通过 MCP 接入）、WorkBuddy（通过 MCP）、n8n（自动化流程）、LangChain/LlamaIndex（AI 应用开发）、Lovable/Bolt.new（AI 应用构建）。也有独立的 CLI 工具可以直接在终端使用。如果你只想简单抓几个网页，直接用 CLI 就行，不需要装别的。

## 客观评价
**优点**：覆盖率极高（96%网页都能抓，含 JS 渲染页面），输出质量干净（Markdown 格式，AI 直接能用），自动化程度高（反爬/代理/限速全自动处理），接入方式丰富（API/MCP/CLI/SDK），还有 AI Agent 功能能自动搜索不需要手动提供 URL。**缺点**：免费额度有限（500次/月），超出要付费；自托管版本配置比较复杂；对中文网页的处理偶尔有编码问题；AGPL 许可证意味着如果你修改并部署给他人使用，必须开源你的改动。**适合谁**：需要让 AI 上网采集数据的人、做竞品分析/舆情监控的人、需要把网页内容喂给 RAG 知识库的人。**不适合谁**：完全不想付费且抓取量很大的人（免费额度不够用）、只需要简单抓几个静态页面的人（用免费工具就够了）。**评分：7/10**。理由：功能强大、生态丰富，但免费额度偏少，自托管门槛中等。

## 未来趋势
① 项目处于**快速增长**阶段，stars 一个月涨几万，MCP 集成刚推出。② 6-12 月内：Agent 功能会更强（自动发现更多数据源）、与 Claude Code/Cursor 等编程工具的集成会更深。③ 关注度评分：**4/5**，AI 数据采集是刚需，Firecrawl 是目前最佳方案之一。
