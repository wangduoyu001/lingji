## 干什么

GPT Researcher 是一个"AI 自动研究员"——你给它一个题目，它自动上网搜索几十条相关资料，读完、分析完，帮你生成一份结构化的研究报告，还带上引用来源。通俗地说，就是把一个人类研究员几天的工作量，压缩到几分钟自动完成。

它的内部工作方式很像一个有分工的小团队：有一个"规划员"先把你的题目拆成几个具体的研究问题，然后"执行员"分头去网上找资料、读网页，最后"报告员"把所有信息汇总成一份完整的报告。这个"多智能体协作"的设计，让它的研究报告比单纯让 ChatGPT 一次性回答要深入和客观得多。

它不仅能搜网上的公开信息，还能读你本地的文件（PDF、Word、Excel 等），把网上信息和你自己的资料结合起来写报告。还支持接入 MCP（Model Context Protocol），可以连 GitHub、数据库等外部工具，让它研究的范围进一步扩大。

## 能实现什么效果

举个例子：你是做投资的，需要快速了解"固态电池最新技术路线和主要玩家"。以前你要自己 Google 几十个网页、读好几篇研报、整理笔记，可能要花大半天。用 GPT Researcher，你输入这个题目，等 5-10 分钟，它给你一份 2000 字以上的报告，里面分几个章节（技术路线、主要公司、投资风险等），每个结论后面还附上了它参考的网页链接。你再花半小时核实和补充，一份初步的调研报告就出来了，原来一天的工作量压缩到 1 小时以内。

另一个例子：你在写论文或者做竞品分析，需要搜集某个话题的多方观点（避免只看到一面之词）。GPT Researcher 会主动去搜不同来源的信息，有意呈现多方观点，而不是只强化某一种立场。它还会在报告里标注"这个信息来自于哪个网页"，方便你回溯和核实，减少 AI 瞎编（幻觉）的风险。

它还能做"深度研究"模式——不是只搜一轮就完事，而是像树一样不断深入：先搜主线，再从每个主线分支出更细的问题，层层深入。这样出来的报告比浅层搜索要详细得多，适合需要深入了解一个领域的场景。

## 怎么用

- **命令行快速用**：`pip install gpt-researcher` 装好 → 写几行 Python 代码（指定研究题目） → 运行 → 几分钟后在当前目录拿到研究报告（Markdown/Word/PDF 格式）
- **网页界面用**：按官方文档用 Docker 部署，或者本地跑起来 → 打开浏览器进入网页界面 → 输入研究题目 → 实时看到它搜索和思考的过程 → 完成后下载报告
- **作为 Python 库集成到自己项目**：`from gpt_researcher import GPTResearcher` 引入 → 在你的程序里调用它做研究 → 把研究结果嵌入你自己的应用或工作流
- **接进 Claude 用**：运行 `npx skills add assafelovic/gpt-researcher` → 在 Claude 里直接让它"帮我深度研究 XX  topic" → Claude 会自动调用 GPT Researcher 完成研究并把结果带回来
- **研究本地文档**：把你的 PDF/Word/Excel 文件指定为研究来源 → 让它"基于这些文件做综合分析" → 它读完整堆文件后写出综合报告，比你一个个文件打开看快得多

## 运行位置

- 🖥️ **本机运行**：Windows/Mac/Linux 都支持，需要能跑 Python 的环境
- 🐋 **Docker 部署**：官方提供 Docker 镜像，一键部署，适合想搭建固定服务的人
- 🌐 **作为在线服务**：官方有 [gptr.dev](https://gptr.dev)，可以直接用，不用自己装
- 🔌 **嵌入别的工具**：可以作为 MCP 服务器接进 Claude Desktop 等工具，也可以作为 Claude Skill 安装

## 需要准备什么

- 💰 **要钱吗**：软件本身开源免费（Apache 2.0 许可证），但运行它需要花钱买 AI 模型的 API（下面详细说明）
- 🔑 **API Key**：需要一个 LLM 提供商的 API Key，默认用 OpenAI（需要去 platform.openai.com 注册、充值）。也可以用其他兼容 OpenAI 格式的 API（比如本地模型、国内大模型的通行证）
- 🔍 **搜索 API**：它需要能搜网页，默认用 Tavily Search API（需要去 tavily.com 注册拿 Key，有免费额度）。也可以配置其他搜索方式
- 💻 **电脑配置**：对电脑本身要求不高，能跑 Python 就行。真正消耗资源的是云端 API，你的电脑只是负责"传话"和"整理结果"
- 📦 **要装什么**：Python 3.11 以上版本，然后 `pip install gpt-researcher` 装依赖。或者用 Docker 的话直接拉镜像就行，不用管依赖

## 配合什么软件

- **独立使用**：有网页界面和 CLI，不需要配合别的软件就能用
- **Claude**：可以作为 Claude Skill 安装，在 Claude 聊天里直接调用研究能力
- **MCP 客户端**：支持作为 MCP 服务器，接进任何支持 MCP 的工具（Claude Desktop、Cursor 等）
- **LangSmith**：支持接入 LangSmith 做运行追踪和可视化（方便调试和研究 AI 的行为）
- **Docker**：可以用 Docker Compose 一键部署完整服务（前端+后端）

## 客观评价

**优点**：
- 开源且功能完整，是目前 GitHub 上 star 最多的"AI 研究员"类项目之一，社区活跃，持续更新
- 多智能体架构设计合理，研究报告质量比让单个 AI 直接回答要好，信息来源更多元、更客观
- 支持的输出格式丰富（Markdown/Word/PDF），拿到的报告可以直接用或者简单加工就用
- 支持本地文档研究，不只是搜网，还能读你自己的资料，实用性更强
- 可以通过 MCP 扩展能力，接入 GitHub、数据库等，研究范围可以进一步扩大

**缺点/坑**：
- 需要自己有 OpenAI API Key 并且充值，每次做深度研究大概花费 0.4 美元（用较便宜的模型），用得频繁的话成本不低
- 安装配置有点麻烦，要配好几个 API Key（LLM Key + 搜索 API Key），对新手不太友好
- 研究报告的质量上限取决于 AI 模型的能力，目前 AI 生成的报告还需要人工核实，不能直接当权威结论用（官方也 disclaimer 了这一点）
- 深度研究模式比较慢，一次完整的深度研究可能需要 5 分钟以上，需要耐心等
- 中文搜索的效果取决于搜索 API 和 AI 模型的中文能力，整体比英文场景稍弱

**适合谁**：需要频繁做调研的研究员、分析师、投资者、内容创作者。也适合开发者想在自己的应用里嵌入"AI 研究"能力。

**不适合谁**：不想折腾 API Key 配置的小白用户；只需要简单问答、不需要深度报告的人（用 ChatGPT 就够了）；预算非常有限、连 API 费用都省不掉的人。

**评分**：8/10 — 在"AI 自动研究"这个垂直方向上功能很完整，开源+可定制是最大优势，但配置门槛和 API 成本限制了它的受众范围。

## 未来趋势

- 📈 **所处阶段**：成长期，star 数 2.7 万说明已经有不少人在用，而且作为"首个开源深度研究智能体"有一定的先发优势
- 🔮 **6-12 个月走向**：随着 Deep Research 功能成为 AI 赛道的热点（OpenAI 自己也出了类似功能），这类工具会越来越多，GPT Researcher 作为开源选手需要持续创新来保持竞争力；预计会加入更多数据源、更好的中文支持、以及更便宜的运行方案（比如默认用本地模型）
- ⭐ **关注度**：4/5 — AI 自动研究是一个非常实用的方向，随着 AI 模型能力持续提升，这类工具的实用价值会越来越大
