## 干什么

Khoj 是一个"个人 AI 第二大脑"——通俗地说，就是给你的笔记、文档、PDF 装上一个能听懂人话的搜索引擎。它的核心本事是：你把 Obsidian 笔记、PDF、Word 文档、Notion 页面等喂给它，之后直接用大白话问问题，它能从你的个人资料里找答案，而不是像普通搜索引擎那样只给你一堆网页链接。

它不像 ChatGPT 那样只聊天上知道的公共知识——Khoj 专门吃你自己的数据。你可以把它想象成"一个住在你电脑里的私人图书管理员"，你问它"我上个月关于竞品分析的笔记里写了什么结论"，它直接去翻你的笔记、PDF、文档，然后把答案端出来，还会告诉你出自哪个文件的哪一段。

它支持同时对接本地模型和云端模型（OpenAI/Claude/Gemini/DeepSeek 等），你可以在"数据不出本机"和"用最强模型"之间切换。还支持创建自定义 AI 代理（Agent），给它指定一个角色（比如"市场调研员"），再喂给它特定的知识库，它就能以这个角色跟你对话和干活。

## 能实现什么效果

举个例子：你有三年的 Obsidian 笔记、几十份 PDF 研报、还有一堆 Word 文档，以前想找某个知识点，得一个个文件夹翻、用 Ctrl+F 搜关键词，经常找不到或者找不全。用了 Khoj，你直接问"我之前对东南亚市场的判断有哪些"，它会在几秒内扫描所有笔记和文档，把相关段落摘出来，还按相关度排好顺序。原来要花半小时翻笔记的事，现在 1 分钟搞定。

另一个例子：你在写一份方案，需要参考之前写过的类似内容。你问 Khoj"帮我找出所有关于用户增长策略的笔记和文档"，它不光列出文件名，还直接把关键段落提炼出来，你可以接着让它"把这些内容整理成一份大纲"，它就能生成一份初步的结构化摘要，你再加工一下就能用，省去了大量复制粘贴的时间。

它还能联网搜索。比如你问"最近关于 AI 监管的新政策有哪些"，它先搜网上的最新信息，再结合你本地的文档给你综合回答。相当于同时拥有"私人知识库"和"实时搜索引擎"两个工具。

## 怎么用

- **问本地笔记**：打开 Khoj 网页/桌面端 → 用大白话问问题（"我之前对 XX 项目的结论是啥"） → 它从你的笔记/PDF 里找答案 → 点击来源直接跳到原文件
- **创建专用 AI 助手**：在 Khoj 里创建一个 Agent → 上传特定资料（比如"竞品分析资料包"） → 设定它的角色（"你是一个市场分析师"） → 之后问它竞品相关问题，它只基于你给的资料回答
- **聊模型对比**：在设置里切换模型（本地用 Llama，复杂任务用 Claude） → 同一个界面，不用分别开不同的网站或软件
- **手机上问笔记**：安装 Khoj 手机版（或连 WhatsApp） → 在外面想到问题，直接问 → 它从你的知识库里找答案，相当于随身带着你的第二大脑
- **自动整理研究资料**：设定一个定时任务 → 它定期帮你汇总某个主题的最新信息 → 整理成简报发到你邮箱

## 运行位置

- 🖥️ **本机运行**：Windows/Mac/Linux 都支持，有桌面应用，也可以自己搭建服务器（Docker 部署）
- 🌐 **网页版**：不想自己装，直接用官方云服务 [app.khoj.dev](https://app.khoj.dev)，注册就能用
- 📱 **手机端**：有手机 App，也支持接 WhatsApp 来问问题
- 🔌 **插件接入**：有 Obsidian 插件、Emacs 插件，在你常用的笔记软件里直接用，不用切换窗口

## 需要准备什么

- 💰 **要钱吗**：云服务有免费额度，高级功能需要付费订阅；自己搭建完全免费（但你需要自己有 API Key 或跑本地模型）
- 🔑 **API Key**：如果要用云端大模型（GPT/Claude/Gemini），需要去对应官网注册拿到 API Key；如果只用本地模型，不需要任何 Key，数据完全不出本机
- 💻 **电脑配置**：用云端模型的话，普通电脑就行；用本地模型需要好一点的显卡（推荐有 8GB 以上显存），不然跑起来会卡
- 📦 **要装什么**：最简单的方式是用官方安装包（Windows/Mac 都有），或者 Docker 一键部署；Obsidian 用户装个插件就能连
- 📂 **数据准备**：把自己想让它读的笔记/PDF/Word 文件整理好，第一次需要让它"索引"（类似让图书管理员先熟悉一下你的书架），索引完才能问问题

## 配合什么软件

- **Obsidian**：有官方插件，装完在 Obsidian 侧边栏里直接问问题，答案来源直接跳转到对应笔记
- **Notion**：可以连接 Notion 页面，让 AI 读你的 Notion 知识库
- **Emacs**：支持 Org-mode 文件，Emacs 用户可以用
- **浏览器**：有网页版，任何电脑打开浏览器就能用
- **手机/WhatsApp**：支持手机 App 和接 WhatsApp，出门在外也能问

## 客观评价

**优点**：
- 真正做到了"个人知识库 + AI"的结合，不是泛泛的聊天机器人，而是能读你自己的数据
- 支持本地模型，担心隐私的人可以做到数据完全不出本机，这一点比很多同类工具强
- 接入方式多样，Obsidian/Emacs/手机/网页全覆盖，使用场景很灵活
- 开源，代码完全公开，可以自己改、自己搭，不用担心厂商跑路或突然收费
- 支持自定义 Agent，可以给不同的任务创建不同的 AI 助手（比如一个专门读法律文档的，一个专门整理读书笔记的）

**缺点/坑**：
- 第一次索引大量文档的时候会比较慢，尤其是 PDF 比较多的话，可能需要等十几分钟到半小时
- 本地模型对电脑配置有要求，低配电脑跑起来会很卡，甚至跑不动
- Obsidian 插件偶尔会有同步延迟，刚改完笔记问它，它可能还没索引到最新内容
- 中文支持还不够完美，搜索中文笔记的效果比英文稍差（语义理解上略有折扣）
- 官方云服务的免费额度有限，重度使用需要付费，价格不算便宜

**适合谁**：有大量个人笔记/文档、希望快速检索和利用这些资料的人（研究员、写作者、知识管理爱好者）。Obsidian 重度用户会特别受用。

**不适合谁**：电脑配置很低、又不想花钱买 API 的人（本地模型跑不动）；资料很少、用 ChatGPT 就够的人（杀鸡用牛刀）。

**评分**：8/10 — 个人知识库 AI 搜索这个方向上做得最成熟的工具之一，开源+支持本地模型是最大优势，中文支持和索引速度还有提升空间。

## 未来趋势

- 📈 **所处阶段**：成长期，star 数 3.5 万说明已经有不少人在用，但还没到大爆发阶段，功能还在快速迭代
- 🔮 **6-12 个月走向**：大概率会加强 Agent 能力（让 AI 不光能回答，还能主动帮你整理、归纳、甚至执行任务）；移动端体验会继续优化；中文支持会逐渐完善
- ⭐ **关注度**：4/5 — 个人 AI 知识库这个赛道会越来越热，Khoj 作为开源选手有较大机会
