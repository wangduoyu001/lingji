# vLLM

> ⭐ 83,406 | 📅 2026-06-20 | [GitHub](https://github.com/vllm-project/vllm)
>
> 💡 **怎么标记**：改上面 `interest` 数字 → 3=必装 2=想试 1=观望 0=跳过 → 改完按 Ctrl+S 保存

## 干什么
vLLM 是一个"大模型推理加速引擎"，就像给 AI 模型装了个涡轮增压——让模型跑得更快、更省显卡内存（就像你开车，普通引擎跑 100km/h，涡轮增压后能跑 200km/h 还省油）。没有它之前，用显卡跑大模型要么速度慢（一次只能处理一个请求），要么显卡内存浪费严重（大量内存空着不能用）。vLLM 用了一种叫 PagedAttention 的技术，像操作系统管理内存一样管理显卡内存，让多个请求同时跑还不卡，显存利用率直接翻倍。它支持 200+ 种模型架构，包括 Llama、Qwen、DeepSeek、GPT-OSS 等所有主流模型。

## 能实现什么效果
如果你要在服务器上给多人提供 AI 服务，vLLM 是目前最好的选择。它能把你的 RTX 4060 Ti 的推理速度提升 2-4 倍，同时处理多个用户的请求不排队。配合 OpenAI 兼容的 API 服务器，你可以搭一个"私有 ChatGPT API"，让团队所有人都能用，而且成本只有云端的几分之一。量化支持（FP8/INT4/INT8）还能让你在小显卡上跑原本需要大显卡才能跑的模型。不过对于单用户个人使用，vLLM 的优势不明显（Ollama 更简单）。

## 怎么用
1. **搭私有 AI API 服务**：vLLM 启动 OpenAI 兼容 API → 团队所有工具都接这个 API → 省掉外部 API 费用
2. **多用户同时用**：vLLM 的连续批处理 → 10个人同时问问题不排队 → 速度还是很快
3. **量化省显存**：INT4 量化 → 8GB 显存跑原本需要 24GB 的模型 → 你的 4060 Ti 也能跑大模型
4. **分布式推理**：多台电脑连起来 → 跑超大模型（70B+） → 成本比云服务低很多
5. **嵌入和检索模型**：vLLM 跑 Embedding 模型 → 给 RAG 系统提供向量检索能力

## 运行位置
需要 Linux 服务器 + NVIDIA GPU（推荐 CUDA 12+）。也支持 AMD GPU、Intel CPU、Google TPU 等多种硬件，但 NVIDIA GPU 是最成熟的选项。Windows 支持有限（主要通过 WSL2）。个人电脑上可以用，但更适合服务器部署场景。

## 需要准备什么
① 完全免费开源（Apache 2.0）。② 不需要注册账号。③ 需要 NVIDIA GPU + CUDA（你的 RTX 4060 Ti 支持 CUDA，可以用）。④ 显存越大越好——8GB 显存用量化能跑中等模型，24GB+ 可以跑大模型不量化。⑤ 需要安装 Python 3.9+ 和 vLLM 包（`pip install vllm` 或 `uv pip install vllm`）。⑥ Linux 环境最佳（Windows 需要 WSL2）。⑦ 内存 16GB+ 推荐。

## 配合什么软件
最佳搭配：Ollama（简单场景用 Ollama，高吞吐场景用 vLLM）、LangChain/LlamaIndex（应用开发）、Open WebUI（前端界面）、LiteLLM（多模型路由）。vLLM 提供 OpenAI 兼容 API，理论上所有支持 OpenAI API 的工具都能接入。

## 客观评价
**优点**：推理速度业界领先（PagedAttention + 连续批处理），显存利用率极高（比原生推理翻倍），支持 200+ 模型架构（基本涵盖所有主流模型），量化支持丰富（FP8/INT4/INT8/GPTQ/AWQ 等），OpenAI 兼容 API 让接入非常简单。**缺点**：偏开发者/企业场景，个人用不如 Ollama 简单；Windows 支持不完善（需要 WSL2）；配置参数多，新手容易搞错；文档偏技术，对非程序员不友好；需要 Linux + NVIDIA GPU 环境。**适合谁**：需要在服务器上给多人提供 AI API 服务的人、追求推理速度和显存效率的开发者、要跑量化模型省资源的人。**不适合谁**：只想在个人电脑简单跑模型的非技术用户（用 Ollama 更好）、没有 NVIDIA GPU 的人、Windows 用户不想装 WSL2 的。**评分：6/10**（对个人非技术用户），**9/10**（对开发者/企业部署）。理由：技术实力顶级，但门槛偏高，不适合你的直接使用场景。

## 未来趋势
① 项目处于**成熟稳定**阶段，已是最主流的推理引擎，2000+ 贡献者维护。② 6-12 月：支持更多硬件（AMD/TPU 持续优化）、量化方案更多、分布式推理更简单。③ 关注度评分：**4/5**，企业部署 AI 的核心基础设施，不会衰退。
