## 干什么

Cherry Studio 是一个"把所有 AI 聊天工具装在一个盒子里"的桌面客户端。它不像那些只能用一个模型的官方客户端（比如只能跟 Claude 聊天的 Claude 官网、只能跟 GPT 聊天的 ChatGPT 官网），而是能同时对接 OpenAI、Gemini、Anthropic、Deepseek、Kimi 等十几个模型服务商，一个软件全搞定。你可以把它想象成"AI 版的 Polytchat（那个能同时用 WhatsApp/Telegram/微信的聊天软件）"——不用在十几个网页之间切来切去，一个窗口全搞定。

它最厉害的地方是"300+ 预配置助手"。装好软件后，你不仅有了一个能聊天的工具，还白捡了 300 多个"专业顾问"——有专门帮你写代码的、有专门帮你写文案的、有专门帮你做数据分析的、有专门帮你学英语的，点一下就能用，不用自己写提示词。相当于请了一个 300 人的专业团队，但不用发工资。

它是开源项目（社区版用 AGPL-3.0 许可证，企业版单独授权），不是某家公司的封闭产品。支持 Windows、Mac、Linux 三个平台，下载安装包就能用，不用配置环境。对于有技术能力的用户，还支持 MCP 协议（Model Context Protocol），可以接入外部工具和数据源，把 Cherry Studio 变成一个"能查数据库、能调用 API、能操作本地文件"的超强助手。

## 能实现什么效果

举个例子：你平时工作要用到好几个 AI 模型——用 Claude 写代码（因为它代码能力强）、用 GPT-4 写英文邮件（因为它英语地道）、用 Gemini 做资料研究（因为它能联网搜索）、用 Deepseek 做中文总结（因为它中文理解好）。以前你要开四个网页、登四个账号、切来切去，非常麻烦。用 Cherry Studio，你在一个软件里配置好这四个模型的 API Key，然后就能在同一个界面里切换使用——写代码的时候选 Claude、写邮件的时候选 GPT-4、做研究的时候选 Gemini、做中文总结的时候选 Deepseek，不用切网页、不用重新登录，效率提升非常明显。

另一个例子：你是内容创作者，需要经常用 AI 帮忙写文案、想标题、做头脑风暴。以前你要自己写提示词（prompt），比如"你是一个资深文案，帮我写一个卖运动鞋的小红书文案"，写不好还要反复调整。用 Cherry Studio，你直接点"文案写作"助手，它会自动加载专业的提示词，你只需要填入你的产品信息（比如"运动鞋、透气、适合跑步"），它就能生成高质量文案。相当于身边有个资深文案专家帮你写提示词，你只要填空白就行。

它还能做"多模型对比"。比如你问一个问题，同时让 Claude、GPT-4、Gemini 三个模型回答，然后你对比哪个回答最好。这个功能在选模型、测模型、或者重要决策需要"多个意见"的时候非常有用。不用分别打开三个网页问三遍，在 Cherry Studio 里一次提问、三方回答。

## 怎么用

- **快速开始**：从 [GitHub Releases](https://github.com/CherryHQ/cherry-studio/releases) 下载对应平台的安装包 → 安装后打开 → 在设置里填入你有的模型的 API Key → 开始聊天 ✓
- **用预配置助手**：打开 Cherry Studio → 在助手列表里搜索或浏览（有 300+ 个） → 点一个你需要的（比如"Python 编程助手"） → 直接开始对话，不用自己写提示词
- **多模型对比**：在对话界面 → 选择"多模型对话"模式 → 勾选你想对比的模型（比如 Claude + GPT-4 + Gemini） → 输入你的问题 → 同时看到三个模型的回答
- **处理文档**：把文本、图片、Office 文件、PDF 拖进对话框 → 让 AI 帮你总结、翻译、提取信息
- **配置本地模型**：先装好 Ollama 或 LM Studio → 在 Cherry Studio 设置里配置本地模型 → 就能在本地离线用 AI（不用花钱买 API）

## 运行位置

- 🖥️ **Windows / Mac / Linux 都可以**：有桌面安装包，下载后像装 QQ 一样装好就能用
- 用云端模型需要联网（调用 API）
- 用本地模型（Ollama/LM Studio）可以完全离线运行
- 不是网页版，是装在本地桌面应用
- 未来会出 Android/iOS 应用（在 Roadmap 里）

## 需要准备什么

- 💰 **要钱吗**：Cherry Studio 软件本身是开源免费的（社区版）。但用哪个 AI 模型就付哪个的钱——如果用 OpenAI 的 GPT-4，需要付 OpenAI API 费用；如果用 Anthropic 的 Claude，需要付 Anthropic API 费用；如果用 Deepseek，需要付 Deepseek API 费用。也可以用本地模型（Ollama），完全不用钱，但需要好点的显卡
- 🔑 **API Key**：根据你要用哪些模型，需要对应的 API Key。可以在 Cherry Studio 的设置界面里逐个配置。如果只想试试，可以先配一个（比如 Deepseek，因为它的 API 比较便宜）
- 💻 **电脑配置**：要求很低，普通办公电脑就行。有 8GB 内存就够了。如果用本地模型，需要好点的显卡（8GB 显存起步）
- 📦 **要装什么**：什么都不用装！下载安装包、安装、打开就能用。如果要本地模型，需要额外装 Ollama 或 LM Studio
- 🌐 **网络**：用云端模型需要能访问对应的 API 服务器（国内访问 OpenAI/Anthropic 可能需要代理）。用本地模型不需要联网

## 配合什么软件

- **独立使用**：主要作为独立桌面应用使用，不依赖其他软件
- **Ollama**：如果想用本地模型且不用花钱，先装 Ollama 并下载模型，然后在 Cherry Studio 里配置
- **LM Studio**：另一个本地模型运行工具，图形界面更友好，也支持
- **WebDAV**：支持用 WebDAV 做文件管理和备份，可以配合 NAS 或云存储使用
- **MCP 服务器**：支持 Model Context Protocol，可以接入各种外部工具（数据库、API、云服务等），把 Cherry Studio 变成超强助手
- **文档工具**：支持处理文本、图片、Office、PDF 等多种格式，可以配合你的文档工作流

## 客观评价

**优点**：
- 一个软件对接所有主流 AI 模型，不用在十几个网页之间切来切去，效率提升明显
- 300+ 预配置助手非常实用，不用自己写提示词，点一下就能用，对新手很友好
- 开源免费（社区版），代码透明，不用担心厂商锁定
- 跨平台支持（Windows/Mac/Linux），覆盖几乎所有桌面用户
- 支持本地模型（Ollama/LM Studio），可以完全离线使用，不用花钱
- 支持 MCP 协议，可以无限扩展能力（高级玩法）
- 完整 Markdown 渲染 + Mermaid 图表可视化 + 代码高亮，写技术文档很方便
- 有开发者共创计划，贡献者能获得 Cursor 赞助、Deepseek/Qwen 无限 API 调用等奖励

**缺点/坑**：
- 社区版用 AGPL-3.0 许可证，商业使用需要注意合规问题（企业用户需要买企业版或注意许可证要求）
- 需要自己准备各个模型的 API Key（或本地模型），对于完全新手来说配置有点麻烦。每个模型服务商都要去注册、申请 Key，比较繁琐
- 本地模型需要好显卡，普通电脑跑不起来或者效果很差
- 一些想要的功能（OCR、TTS、ASR、插件系统）还在 Roadmap 里，目前用不了
- 移动端（Android/iOS）还在开发中，目前只能桌面用
- 没有内置 API 中转功能，如果需要统一管理多个 API Key，需要配合 new-api/one-api 等项目使用
- 因为是对接别人家的 API，如果 API 服务挂了或者限流了，Cherry Studio 也用不了（这不是 Cherry Studio 的问题，是所有第三方客户端的通病）

**适合谁**：需要用多个 AI 模型的用户（比如同时用 Claude 写代码 + GPT-4 写邮件 + Gemini 做研究）、想要"开箱即用不用写提示词"的新手、对数据安全有要求想用本地模型的用户。

**不适合谁**：只用某一个模型（比如只用 ChatGPT）的用户（直接用官网更方便）、没有 API Key 且不想搞本地模型的用户（用不了）。

**评分**：8/10 — 多模型整合做得最好、预配置助手很实用，但配置门槛和许可证需要注意
