# 🀄 麻将类主播分析

> 2组主播 · 两大派别（玄学派 vs 课程派）

## 主播列表

| 主播 | 风格 | 变现路径 |
|------|------|---------|
| [[九哥讲国粹]] | 玄学派 - 情感操控最重 | 符咒福袋 |
| [[课程派三人组]] | 课程派 - 3人合并（同模板不同差异） | 98元课程/粉丝群 |

## 品类话术规律

- **共同痛点**：「先赢后输」「十打九输」「打一辈子还输」→ 精准命中
- **共同归因**：不是你技术差，是运气差 → 运气可控，我卖「控制运气的方法」
- **变现模式**：先给甜头（免费教学）→ 建立信任 → 开始变现
- **核心SOP**：痛点 → 颠覆归因 → 免费教学 → 限时卖课

## 两大派别对比

| 维度 | 九哥讲国粹（玄学派） | 课程派三人组 |
|------|-------------------|-------------|
| 变现产品 | 福袋/符咒(39.9元起) | 课程(98元) |
| 教学含量 | 极低，几乎无实质 | 中高，有实质内容 |
| 核心说服逻辑 | 转运→赢钱 | 技术提升→赢钱 |
| 情感操控程度 | 极高 | 中等 |
| 产品可信度 | 疑似智商税 | 相对可信 |
