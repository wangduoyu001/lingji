## 话术手法总结

### 核心套路

1. **知识带货模式**：以大量实质教学内容（天干地支查找方法）为核心，用真正的知识点建立信任，然后在教学过程中自然插入引流动作
2. **资料引流**：反复将"讲义""笔记""口诀资料"作为钩子引导进铁粉群，共计4-5次
3. **分层留人**：年份→月份→日时，层层递进，用"后面的才是干货""重点在后面"持续留人
4. **互动式教学**：通过答题、考试、出题等方式持续互动，让观众产生参与感和"学会了"的成就感

### 隐晦话术清单

| 话术 | 表面意思 | 实际意图 |
|-----|---------|---------|
| "公益直播间""不用送礼物" | 声明无私公益 | **B03立人设+C04营销铺垫**：公益人设降低戒心，随即要求亮灯牌（付费行为） |
| "真传一句话，假传万卷书" | 国学俗语 | **B02稀缺性**：暗示她的内容是"真传"，别人都是"假传"，制造排他性 |
| "师出名门，一脉正传" | 正统传承 | **B03立人设**：暗示自己传承正统，别家不正宗 |
| "研究国学20年" | 专业背景 | **B03立人设**：时间积累=权威，但无法验证 |
| "一共一百多页"分享到群里 | 内容丰富 | **C02引导粉丝群+C04营销铺垫**：用内容量暗示价值，引流进群获取 |
| "年份只是开胃菜" | 内容分层 | **C04营销铺垫+A02要停留**：暗示后面更值钱，留人+制造期待 |

### 变现路径

```
免费直播教学(建立信任) → 讲义资料钩子(进铁粉群) → 群内班主任服务 → 后续付费课程/私域服务
```

**核心变现模式**：以国学教学为内容载体，通过免费直播提供实质知识点建立信任，用"讲义资料"引导进铁粉群完成私域引流，群内由班主任跟进后续付费课程。相比创业类主播，该主播知识输出比例较高，但引流手法依然贯穿全程。
