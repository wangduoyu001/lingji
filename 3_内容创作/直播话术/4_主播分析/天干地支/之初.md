## 话术手法总结

### 核心套路

1. **知识带货模式**：以大量实质教学内容为核心，全程手把手教天干地支查找方法，知识点密度极高，真正有学习价值
2. **持续互动教学**：通过"飘年份""打对""打6打2"等方式高频互动，让观众产生参与感和成就感
3. **资料引流**：反复将口诀、节气表、对照表等资料作为钩子，暗示"放里边""自行去看"，引导进群
4. **分层留人**：年→月→日时，层层递进，"后边才是重点"持续留人

### 隐晦话术清单

| 话术 | 表面意思 | 实际意图 |
|-----|---------|---------|
| "公益在这里分享" | 声明无私 | **B03立人设**：公益人设降低戒心，但随即要求关注+粉丝团+灯牌 |
| "随缘不攀缘" | 不强求 | **B03立人设**：淡泊人设，但实际高频要求关注 |
| "一半同学关注都没点，不知道是我讲的不值得你一个关注" | 自嘲 | **A04要关注+C01要关注(转化)**：情感绑架式催关注，制造愧疚感 |
| "不会的自行复习""放里边你们都能看见" | 提供资料 | **C02引导粉丝群**：暗示群里有完整资料，引流进群 |
| "口诀记不住没关系，会找会用就行" | 降低门槛 | **C04营销铺垫**：降低流失+暗示群里有现成资料不用背 |

### 变现路径

```
免费直播教学(建立信任) → 口诀/节气表等资料钩子(进群) → 粉丝团+灯牌(小额付费) → 群内持续服务 → 后续付费课程/私域服务
```

**核心变现模式**：以天干地支教学为核心内容，通过免费直播提供高质量知识点建立信任，用"口诀资料""节气表"等引导进群完成私域引流，同时通过粉丝团+灯牌实现小额变现。知识输出比例在四个天干地支主播中最高，是最接近"真教学"的主播，但引流手法依然贯穿全程。
