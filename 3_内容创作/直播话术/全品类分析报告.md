## 二、各品类话术特征详解

### 2.1 创业类（露九橙）

**全文特点**：75分钟超长直播，几乎全是话术，零实际内容。从开场到结尾一直在做营销漏斗。

**话术结构流**：
```
学历贬值→劳动力贬值→人口危机→AI替代→"四个赚钱方向"→抖店商城→拼手速领门票→加群
```

**深扒动作**：

- **【B01 痛点-焦虑制造】★★★★★**
  - "学历贬值，大学生毕业送外卖" → 制造学历无用焦虑
  - "3400万网约车司机面临失业" → 制造职业焦虑
  - "机器人会生孩子，会相夫教子" → 制造存在焦虑
  - 以上都不是在讲新闻，是在系统性摧毁观众的安全感

- **【C04 推销前铺垫-隐藏最深】★★★★★**
  - 整个前半场（约40分钟）全是铺垫，一字不提"卖什么"
  - "危机=危+机" → 为后面"我给你们找到机会"埋伏笔
  - "信息差改变命运" → 反复植入这个锚点
  - "我是杭州有公司的、有几百人团队" → 用实力证明"我能带你"

- **【B03 立人设】★★★★**
  - "我不卖课不卖货"（说了至少5遍，每遍都是在卖）
  - "我只讲真话，我很敢讲" → 建立信任人设
  - "老朋友都知道我搞互联网的，搞的还行" → 结果型立人设

- **【B04 洗人群】★★★★**
  - "低认知的根本听不懂" → 排除法筛选
  - "三天打鱼两天晒网的不要来" → 门槛设置
  - "成年人只做筛选不做选择" → 反向施压

- **【C05 催单逼单】★★★★**
  - "只剩28个名额了" → 人为稀缺
  - "只有一分钟，一分钟之后就下掉" → 时间压力
  - "最后两张" → 反复制造紧迫感（实际说了5遍"最后"）

- **【关键发现】**：
  > 整场直播有一条暗线：先让你觉得世界要完了 → 再给你看"别人跟着我赚了3.2万单" → 最后说"我有门票，免费的，但只剩几张了"。全程不提"卖"，全程在卖。这叫**焦虑-希望-行动**的经典转化漏斗。

### 2.2 天干地支类（中庸等5个文件）

**品类特征**：这5个文件结构高度相似，都是"传统文化教学"风格。核心是教你用"掌诀法"推算天干地支。

**共性话术手法**：

- **【B03 立人设-学术权威】**
  - "师出名门，一脉正传" → 继承型权威
  - "真传一句话，假传万卷书" → 碾压同行

- **【C04 营销铺垫-隐藏】**
  - 全程教"免费知识"，但结尾必定引流（进群/加微信）
  - "我把这张图发到铁粉群里" → 用免费内容换关注和私域

- **【A03 要互动-扣数字】**
  - 大量"知道答案的扣1""大家打出来"
  - 用互动制造参与感，同时做数据

- **变现模式**：教学→建立信任→私域→付费咨询/风水服务

---

### 2.3 易经类（2个文件）

**品类特征**：学术感最强的一个品类。引用大量古籍和历史人物。

**核心话术**：

- **【B03 立人设-最强】**
  - "人更三圣，世立三古" → 伏羲、文王、孔子三级背书
  - "群经之首" → 终极权威定位

- **【C04 营销铺垫】**
  - 讲八卦起源、六十四卦 → 让你觉得"这东西太深了，我学不会"
  - 学不会就有付费需求

- **变现模式**：公开课引流 → 私域 → 付费课程

---

### 2.4 道家小妙招类（任平安等2个文件）

**品类特征**：最贴近日常生活的品类。不直接带货，但隐晦指向"你需要这些东西"。

**核心话术拆解**：

- **【B01 痛点-恐惧驱动】★★★★★**
  - "身上穿的衣服不要随便丢，带着你的气" → 恐吓
  - "家里碎碗要妥善安置，不然会有祸" → 恐吓
  - "外人来你家哭闹，会把好运气吵散" → 恐吓
  - **以上所有"建议"的本质都是在制造恐惧，让你觉得"不做会有后果"**

- **【B03 立人设-奉献型】**
  - "我学习传统文化21年了" → 资历
  - "我师父是蒲阳书院的" → 传承背书
  - "我不卖课不卖货，只结善缘" → 奉献型人设（之后再慢慢转化）

- **【C04 营销铺垫-最阴险】★★★★★**
  - 讲12个月的"注意事项"，每个月份都指向不同的"解决方案"
  - 正月要穿水晶 → 暗示你买水晶
  - 三月要带黄玉印章 → 暗示你买黄玉
  - 八月要编蚕丝绳绑脚踝 → 暗示你买蚕丝绳
  - **全程不说"买"，全程在制造"你需要"**

- **【B04 洗人群】**
  - "信则有，不信则无" → 信的人才是我要的人
  - "您打了关注就是有缘人" → 筛选式夸奖

### 2.5 麻将类（4个文件）

**品类特征**：这个品类最复杂——既有真实技术教学，又有大量迷信和商品变现。

**九哥讲国粹/麻将/麻将技术指导 共性手法**：

- **【B01 痛点-最强】★★★★★**
  - "你是不是先赢后输？"
  - "你是不是十打九输？"
  - "你是不是打了一辈子还在输？"
  - **精准戳中麻将爱好者的核心痛苦**

- **【B03 立人设-多重】**
  - "别人坐飞机坐高铁来我培训班学" → 结果型
  - "同行藏着掖着，我今天全告诉你" → 碾压同行+稀缺
  - "我是职业比赛的" → 专业性
  - "我线下学员学完每天啥也不干专门靠这个吃饭" → 极端案例立人设

- **【B02 稀缺]★★★★**
  - "平时我直播间从来不讲这些" → 制造稀缺
  - "花了再多钱学不到" → 稀缺
  - "今天不讲以后可能听不到" → 时间稀缺

- **【C04 营销铺垫-C05 逼单】★★★★★**
  - 九哥：铺垫→"麻将机原理"→"打骰子方法"→推福袋→推符咒→推橱窗
  - 麻将(另一主播)：铺垫→"逆风局打法"→"100节课只要98"→小黄车
  - 两者结构完全一致：**先给甜头（免费方法）→建立信任→开始变现**

- **【独特手法-命运归因】**
  - "你输不是技术差，是运气差" → 把客观事实归因为可操控的玄学
  - 既然运气可控（打骰子/推牌/符咒），那我卖的就是"控制运气的方法"

## 三、跨品类话术共性规律

### 3.1 五大品类都用的「暗线结构」

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 制造焦虑  │ → │ 建立信任  │ → │ 给解决方案 │ → │ 行动号召  │
│ (B01/B02) │    │  (B03)   │    │ (C04/B05) │    │ (C01-C05) │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 3.2 最容易漏判的隐晦动作

| 表面说法 | 关键词匹配判断 | 真实意图 |
|----------|---------------|---------|
| "我今天免费分享" | A01开场 | B03立人设 + C04营销铺垫 |
| "你不相信我，现在就走" | 无 | B04洗人群（反向筛选） |
| "我熬到凌晨整理的" | 无 | B03立人设 + C04营销铺垫 |
| "这个东西平时我不讲" | 无 | B02稀缺 + C04营销铺垫 |
| "你自己决定要不要了解" | 无 | C05逼单（以退为进） |
| "我图你什么？" | 无 | B03立人设（消除防备） |
| "成年人只做筛选不做选择" | 无 | B04洗人群 + C05逼单 |

### 3.3 各品类C04（营销铺垫）的出现频率

| 品类 | C04密度 | 变现直接度 |
|------|---------|-----------|
| 创业（露九橙） | 极高（全文都是） | 极高（加群→课程） |
| 麻将（九哥） | 极高 | 极高（符咒+课程） |
| 麻将（麻将豪哥） | 高 | 高（课程小黄车） |
| 道家小妙招 | 高（隐藏） | 中（间接） |
| 天干地支 | 中 | 中（私域转换） |
| 易经 | 中 | 中（课程咨询） |
