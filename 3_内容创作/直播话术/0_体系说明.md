# 📖 话术库分类体系说明

## 目录结构

```

├── 1_总索引.md          ← 首页入口，一页看全部

├── 1_完整文档/          ← 每场直播的完整原文
├── 2_动作话术/          ← 按直播动作分类的话术片段
├── 3_来源索引/          ← 按来源查看的话术片段索引
```

## 核心：动作话术分类

直播话术按「铺垫+执行」模式拆分为以下动作类型：

### 🎬 暖场与留人
| 编号 | 分类 | 说明 |
|------|------|------|
| A01 | 开场暖场 | 欢迎、自我介绍、直播间定位 |
| A02 | 要数据(停留) | "不要划走"、"停留几分钟"等留人话术 |
| A03 | 要互动(扣数字) | "扣1扣2"、"打个数字"等互动引导 |
| A04 | 要互动(回答问题) | 用提问引导公屏互动 |
| A05 | 要点赞 | 引导点赞的各种话术 |

### 🎣 钩子与信任
| 编号 | 分类 | 说明 |
|------|------|------|
| B01 | 放钩子(痛点) | "总是输"、"学不会"等扎心话术 |
| B02 | 放钩子(稀缺) | "只教一次"、"最后一遍"等紧迫话术 |
| B03 | 立人设 | "我不教这个"、"我手把手教"等权威建立 |
| B04 | 洗人群 | "刷到我就是缘分"、"大数据推给你"等筛选 |
| B05 | 放福利/红包 | 福袋、红包引导话术 |

### 🛒 转化与引导
| 编号 | 分类 | 说明 |
|------|------|------|
| C01 | 引导关注/加粉 | 点关注、加粉丝群话术 |
| C02 | 引导橱窗/商品 | 卖货、下单话术 |
| C03 | 引导风车/卡片 | 技术性引导动作 |
| C04 | 推销前铺垫 | "这个东西我一般不说的"等铺垫 |
| C05 | 催单与逼单 | "最后几个"、"不接就下播" |

### 👋 收尾
| 编号 | 分类 | 说明 |
|------|------|------|
| D01 | 预告下播 | "下播了"、"明天见" |
| D02 | 粉丝维护 | 老粉互动、账号变更说明 |
| D03 | 告别 | 再见话术 |

## 在Obsidian里怎么用

- **首页看全部**：打开 `1_总索引`，一页总览所有主播、品类、动作分类
- **按品类查主播**：打开 `4_主播分析/` 下对应品类文件夹，看单主播完整拆解
- **按动作找话术**：打开 `2_动作话术/` 下对应的文件，看所有主播对这个动作怎么说的
- **看完整原文**：打开 `1_完整文档/` 下对应原文，看完整语境
- **按来源查看**：打开 `3_来源索引/` 下按主播分的索引
- **横向对比**：打开 `全品类分析报告` 看5品类话术共性规律
- **标签检索**：用 `#话术/A01_开场暖场` 等标签快速筛选
