# ⚡ 1 分钟速查

## 我要干什么 → 怎么办

| 我要…… | 操作 |
|---------|------|
| 看看今天有什么新项目 | 点左边「每日总结」文件夹 → 选最新日期 |
| 标记一个项目想试 | 点项目 → 改 `interest: 2` → Ctrl+S |
| 标记一个项目跳过 | 点项目 → 改 `interest: 0` → Ctrl+S |
| 标记已安装 | 点项目 → 改 `status: 已安装` → Ctrl+S |
| 找所有「必装」项目 | 点 `00_项目管理.md` → 看 🔴 区域 |
| 找「写代码」类的工具 | 点 `01_AI编程工具.md` |
| 找「一个人干」的工具 | 点 `04_OPC一人公司.md` |
| 搜项目名 | Ctrl+Shift+F → 输入名字 |
| 看不懂项目是干嘛的 | 翻到「干什么」和「能实现什么效果」两段 |
| 纠结要不要试 | 翻到「客观评价」，看优缺点和门槛 |
| 想知道能不能跑得起来 | 翻到「需要准备什么」和「运行位置」 |

## 标记速查

```
interest: 3 = 🔴 必装
interest: 2 = 🟡 想试  
interest: 1 = 🟢 观望
interest: 0 = ⚫ 跳过

status: 未试 / 已安装 / 在用 / 已弃用 / 不合适
```
