# RAGFlow

> ⭐ 83,235 | 📅 2026-06-20 | [GitHub](https://github.com/infiniflow/ragflow)
>
> 💡 **怎么标记**：改上面 `interest` 数字 → 3=必装 2=想试 1=观望 0=跳过 → 改完按 Ctrl+S 保存

## 干什么
RAGFlow 就像一个"AI 私人图书馆管理员"——你把各种文档扔给它（Word、PPT、PDF、扫描件、网页、Excel，什么格式都行），它会自动整理、分类、提取关键信息，然后让 AI 基于这些真实文档来回答你的问题（就像图书馆管理员帮你找书，而不是 AI 随口编答案）。没有它之前，AI 回答问题经常"编故事"（俗称幻觉），因为 AI 并不知道你的真实数据。有了 RAGFlow，AI 的每个回答都有出处，你可以看到它引用了哪页文档，不用担心它胡说八道。它还支持 Agent 功能，让 AI 不只是回答问题，还能自动执行任务（写代码、调用工具、编排工作流）。

## 能实现什么效果
用了 RAGFlow，你可以搭建一个"企业级知识库问答系统"。把你的直播话术文档、运营数据、对标账号分析报告全扔进去，然后直接问 AI："这个主播这周的话术有什么变化？"AI 会从你的真实文档里找答案，还告诉你引用了哪份文件。对于做直播运营的你来说，这意味着你可以把所有话术素材、监控数据、竞品分析都变成一个可查询的"AI 智囊团"。中文支持非常好（毕竟是中国团队做的），界面也是中文的，不像很多国外工具需要汉化。

## 怎么用
1. **直播话术知识库**：上传话术文档 → RAGFlow 自动解析 → 问"这个话术的关键转化点在哪" → AI 从文档里精准回答并标注出处
2. **竞品分析问答**：批量上传对标账号数据 → 问"最近谁涨粉最快" → AI 从数据里找答案
3. **企业文档助手**：把合同、PPT、会议纪要全上传 → 问"上次会议决定了什么" → AI 从会议纪要里回答
4. **AI Agent 自动执行**：RAGFlow 的 Agent 功能 → 设定"每天自动抓取行业报告" → 自动执行并入库
5. **飞书/Discord 集成**：RAGFlow 接到飞书群 → 群里直接问问题 → AI 从知识库回答

## 运行位置
主要通过 Docker 在本地或服务器上部署。也可以用云端版（cloud.ragflow.io），免安装直接用。本地部署需要 Docker（Docker Compose ≥ v2.26.1），支持 Linux、macOS、Windows（通过 Docker Desktop）。最低配置：4核CPU、16GB内存、50GB磁盘。有 GPU 加速模式可选（需要 NVIDIA GPU + CUDA）。

## 需要准备什么
① **完全免费**开源，Apache 2.0 许可证。② 云端版有免费额度，超出付费。③ 不需要注册账号（本地部署）。④ 本地部署需要 Docker（要安装 Docker Desktop）。⑤ 电脑配置：最低 4核CPU + 16GB内存 + 50GB磁盘（你的 i7-9700 + 16GB 内存刚好够最低要求）。⑥ 需要 Python 3.13+（开发模式下）。⑦ 如果要用 GPU 加速，需要 NVIDIA 显卡 + CUDA（你的 RTX 4060 Ti 支持）。

## 配合什么软件
最佳搭配：飞书（聊天机器人集成）、Ollama（本地模型后端）、LangChain（扩展开发）、MinIO/MySQL/Elasticsearch（RAGFlow 内部已包含，不需要单独装）。独立使用也行，自带完整 Web 界面。还支持 MCP 协议，可以接到 Claude Code/WorkBuddy。

## 客观评价
**优点**：中文支持极好（界面、文档、社区都有中文），文档解析能力强（扫描件、PPT、PDF 都能处理），回答有出处（减少幻觉），Agent 功能丰富（MCP + 代码执行 + Memory），部署虽然需要 Docker 但一键命令就行。**缺点**：最低 16GB 内存要求对低配电脑有门槛，Docker 部署对新手不友好（需要先装 Docker），暂不支持 ARM64（树莓派/M1 Mac 服务器不能直接用官方镜像），开源版功能比云端版少一些。**适合谁**：需要搭建中文知识库问答的人、想让 AI 回答有出处的人、有 Docker 经验或愿意学的人。**不适合谁**：电脑内存不到 16GB 的人（会很卡）、不想装 Docker 的人（只能用云端版）。**评分：8/10**。理由：中文 RAG 最佳方案，功能全面、回答可信，但 Docker 门槛对非技术用户稍高。

## 未来趋势
