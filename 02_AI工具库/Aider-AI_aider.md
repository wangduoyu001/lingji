# Aider

> 💡 **怎么标记**：改上面 `interest` 数字 → 3=必装 2=想试 1=观望 0=跳过 → 改完按 Ctrl+S 保存

## 干什么

Aider 是"AI 结对编程"的鼻祖级工具——你在终端里写代码，AI 在旁边像一位资深搭档一样帮你改代码、提建议、解释逻辑。Aider 的特点是轻量和精准：它不像 Claude Code 那样全家桶，也不像 ChatGPT 那样通用，而是专注于一件事——帮你改代码。它直接在你的 Git 仓库里工作，理解你的项目结构、读你所有的代码文件、然后精准修改你指定的部分。它最早引入了 AI 结对编程的概念，现在依然是这个方向最受推崇的工具之一。

## 能实现什么效果

装了 Aider 之后，你的编程体验变成这样：你在编辑器里写代码，Aider 在终端里随时待命。你需要加一个功能——在终端里描述一下要做什么，Aider 自动创建新文件、写代码、添加到 Git。改完之后你发现有个 bug——告诉 Aider 哪里有问题，它自动定位、修改、验证。最难能可贵的是它有 SWE-bench（软件工程基准测试）的公开排名，Aider 在这个权威测试中一直排名前列，说明它的代码修改准确率是经过验证的。它支持几乎所有主流大模型——OpenAI、Claude、Gemini、本地 Ollama 等。

## 怎么用

- **加功能**：在项目终端里 → `/aider "给 User 模型加一个 phone_number 字段，并更新注册表单"` → Aider 自动改 model、改 view、改 migration
- **改代码**：选中一段代码 → `/aider "把这段 for 循环改成 list comprehension"` → 自动优化
- **修 Bug**：程序报错 → `/aider "这个错误是 XXX，帮我修复"` → 自动分析错误 → 修复代码
- **写测试**：函数写完了 → `/aider "给这个函数写单元测试，覆盖所有边界条件"` → 自动生成测试代码
- **代码解释**：看不懂一段老代码 → `/aider "解释这段代码在做什么"` → AI 用自然语言解释

## 运行位置

- **本地电脑**：终端工具，pip 安装，Windows/Mac/Linux
- 在你项目的 Git 仓库中运行
- Python 开发
- 支持命令行界面，也可以配合 VS Code 终端

## 需要准备什么

- **费用**：免费开源（Apache 2.0）
- **账号**：不需要
- **API Key**：需要 LLM API Key（OpenAI/Claude/Gemini/Ollama 等至少一个）
- **电脑配置**：极低——任何能跑 Python 的电脑都行（不跑模型，只调用 API）
- **软件依赖**：Python 3.10+, Git

## 配合什么软件

需要在 Git 仓库中使用。配合 VS Code 或任何编辑器的终端使用效果最佳。可以配合 Ollama 使用本地模型降低成本。

## 客观评价

优点：① 精准高效——专注于代码修改这件事，做得非常深；② SWE-bench 排名高，代码修改准确率有数据背书；③ 轻量——pip 安装一条命令，不像某些工具要装 Docker 全家桶；④ 模型选择自由——不绑任何一家，想用谁用谁。

缺点/坑：① 功能单一——如果除了改代码还需要生成 PPT、做数据分析，它帮不了你；② 没有图形界面，全靠终端输入，非程序员会觉得像 DOS 时代；③ 对大项目可能有上下文限制——一次只能"看到"有限数量的文件；④ API 费用跟使用频率成正比，用了就花钱。

适合谁：程序员、经常改代码的开发者、需要 AI 辅助但不想要全家桶的人。不适合：非程序员、需要全能 AI 助手的人、对终端操作陌生的人。

打分：8.5/10。在"AI 帮你改代码"这一件事上做到了极致。扣 1.5 分因为功能单一和终端门槛。
