## 干什么

Claude Code 是一个能帮你写代码、改代码、找 bug 的 AI 助手。它不像 ChatGPT 那种网页聊天——它是直接装在你电脑的终端（黑窗口）里，能直接读你电脑上的代码文件、直接帮你改。你可以把它想象成"一个坐在你旁边的程序员帮手"，你跟它说话，它帮你干活。

它最大的本事是能理解你整个项目的代码结构，不是只看一个文件。比如你跟它说"帮我把所有错误提示都改成中文"，它会自己在几百个文件里找、然后逐个改，不用你一个个点开。

它是 Anthropic 公司（做 Claude 聊天机器人的那家公司）官方出的工具，不是第三方山寨货。用的是 Claude 模型，代码理解能力是目前市面上最强的之一。

## 能实现什么效果

举个例子：你有一个网站项目，想让所有按钮从蓝色改成红色。普通做法是打开几十个文件、一个个找按钮的颜色代码、手动改。用 Claude Code，你只需要在终端打一句话："把所有按钮的颜色从蓝色改成红色"——它会在几秒内扫描整个项目、找出所有按钮样式、逐个改好。你审查一下改动对不对，满意了就保存。省下的时间可能从 2 小时变成 5 分钟。

另一个例子：项目报错了，你对着满屏英文报错不知道哪里出问题。把报错信息丢给它，它能读出是哪个文件的哪一行出错了、怎么修、为什么出错。相当于身边有个 24 小时不睡觉的高级程序员帮你 debug。

它还能帮你写新功能。你说"我要一个搜索框，输入文字后筛选列表"，它直接生成完整代码，附带注释解释每段在干什么。

## 怎么用

- **改样式**：打开项目终端 → 说"把登录页面的输入框改成圆角" → 审查改动 → 保存 ✓
- **修 bug**：复制报错信息 → 丢给 Claude Code → 看它分析原因和修复方案 → 执行修复
- **写新功能**：描述你要什么功能（比如"加一个导出 CSV 的按钮"） → 它生成代码 → 你试运行 → 有问题继续让它改
- **看不懂代码**：选中一段别人写的代码 → 让它"用大白话解释这段在干什么" → 快速理解
- **写测试**：跟它说"给这段代码写测试用例" → 自动生成测试，帮你验证代码不会出错

## 运行位置

- 🖥️ **Windows / Mac / Linux 都可以**：在终端（命令行）里运行
- 需要联网（它要调用 Claude 的云端 AI 才能工作）
- 不是网页版，是装在本地的命令行工具

## 需要准备什么

- 💰 **要钱吗**：要。需要 Anthropic 的 API 账号，按用量付费。写代码的量不大的话，一个月几十块钱。先去 anthropic.com 注册，然后在后台生成一个 API Key
- 🔑 **API Key**：Anthropic API Key（像一串密码，证明你有权使用 Claude 服务）。免费注册后可用，但额度有限
- 💻 **电脑配置**：要求不高，普通办公电脑就行。有 8GB 内存就够了。不需要显卡（AI 运算在云端）
- 📦 **要装 Node.js**：需要先装 Node.js 18 以上版本（免费的，去 nodejs.org 下载安装就行）。安装命令：`npm install -g @anthropic-ai/claude-code`
- 🌐 **网络**：需要能访问国外的 Anthropic 服务器。如果网络不通需要代理

## 配合什么软件

- **终端**：必须配合终端使用（Windows 的 PowerShell 或 CMD、Mac 的 Terminal）
- **VS Code**：有配套插件，可以在 VS Code 里用，不用切到终端
- **JetBrains 系列**：支持 IntelliJ、PyCharm、WebStorm 等编辑器
- **Git**：强烈建议项目用 Git 管理（这样 Claude Code 改错了可以一键回退）

## 客观评价

**优点**：
- 代码理解能力是同类中的第一梯队，能看懂整个项目结构而不只是一个文件
- Anthropic 官方出品，更新快、质量有保证，不用担心跑路
- 支持 MCP 协议，可以接入自己的工具和数据库（高级玩法）
- 像真人在帮你而不是机器，对话自然，能记住上下文

**缺点/坑**：
- 对网络有要求，国内直连可能很慢或连不上，需要搞定代理
- API 按量付费，改大型项目可能烧钱快（虽然 Anthropic 有免费额度）
- 必须在终端用，不熟悉命令行的人上手需要一点学习成本
- 偶尔会改错代码，需要你自己会判断对错（不能完全甩手不管）
- 不像 VS Code 插件那样嵌入编辑器里操作，它更像一个独立外挂

**适合谁**：已经有编程基础、想提升效率的人。不适合完全零基础想从零学编程的人（它不是教程工具，是干活工具）。

**不适合谁**：完全不知道什么是终端的人、没有编程经验的人（它不是"不写代码做网站"那种工具，你需要有基本的代码判断力）。

**评分**：8/10 — 同类中功能最强，但入门门槛和网络要求扣分
