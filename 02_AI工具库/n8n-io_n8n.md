# n8n

>
> 💡 **怎么标记**：改上面 `interest` 数字 → 3=必装 2=想试 1=观望 0=跳过 → 改完按 Ctrl+S 保存

## 干什么

n8n 是一个"搭积木"式的自动化工作流平台，现在集成了 AI 能力。就像拼乐高一样——你拖拽不同的模块（比如"收到邮件"→"AI分析内容"→"自动回复"→"记录到表格"），把它们连起来，一个自动化的 AI 工作流就做好了。以前做自动化需要写代码，n8n 用可视化的方式让不会编程的人也能做。它支持 400 多种应用的连接（Gmail、Slack、数据库、API 等），而且你可以选择自己装在自己电脑上或服务器上（数据不传给别人），也可以用官方云服务。

## 能实现什么效果

用了 n8n 之后，很多重复性的工作就变成全自动的了。比如你是一个做电商的——每当有人在淘宝下单，n8n 能自动：从订单中提取信息 → 用 AI 生成感谢邮件 → 发给客户 → 把订单记入 Excel → 通知仓库发货。全程不需要你点一下鼠标。再比如做内容运营——n8n 可以每天早上自动：抓取当天的热点新闻 → 交给 AI 总结成 3 条要点 → 自动发布到你的飞书群。以前这些事需要 2-3 小时，现在零秒完成。

## 怎么用

- **电商订单处理**：淘宝有新订单 → n8n 触发 → AI 分析客户信息生成个性化感谢 → 自动发邮件 → 更新库存表
- **内容自动发布**：每天早上 8 点 → 抓取 RSS 新闻 → AI 筛选跟你的行业相关的 → 改写后自动发到公众号草稿箱
- **客户服务**：客户发邮件询问 → n8n 收到 → AI 理解问题 → 如果是常见问题自动回复，复杂问题转人工
- **数据监控**：设置监控规则 → n8n 每 10 分钟检查一次数据库 → 发现异常数据 → AI 分析原因 → 发飞书通知
- **文档处理**：收到 PDF 合同 → n8n 自动提取关键条款 → AI 审核是否存在风险 → 标记问题项 → 发给法务

## 运行位置

- **本地电脑**：Windows/Mac/Linux 都能自建部署（Docker 或 npm 安装）
- **自己服务器**：推荐方式，部署到自己的云服务器上，7x24 运行
- **云端服务**：n8n 官方提供云版本（付费），不需要自己维护服务器
- TypeScript 开发，有 Web 图形界面操作

## 需要准备什么

- **费用**：自建版本免费开源（fair-code 协议）；云版本收费（约 $20/月起）
- **账号**：自建不需要；云版本需要注册 n8n 账号
- **API Key**：如果你要用 AI 模块（如 ChatGPT 节点），需要 OpenAI 或 Claude 的 API Key
- **电脑配置**：自建部署建议 4GB 以上内存的服务器或电脑；仅运行工作流消耗不高
- **软件依赖**：自建需要安装 Node.js（20+）或 Docker

## 配合什么软件

独立使用，自带 Web 管理界面。但如果你要用 AI 能力，需要配合大模型 API（OpenAI/Claude/Gemini）。可以连接的应用包括：Gmail、飞书、Slack、企业微信、数据库（MySQL/PG）、各种 API。

## 客观评价

优点：① 对非程序员极其友好——拖拽式操作，像画流程图一样做自动化；② 400+ 连接器，几乎覆盖了市面上所有主流工具；③ 自建部署数据安全，不需要把敏感信息传给第三方；④ AI 模块是原生内置的，不需要额外装插件。

缺点/坑：① 虽然是"fair-code"，但如果想用于商业付费服务有额外限制；② 云版本对国内网络不太友好，自己部署也有一定技术门槛；③ 复杂工作流调试比较困难，出错时排查麻烦；④ 部分 AI 模块还比较初级，不如专门 AI 工具灵活。

适合谁：需要自动化的运营人员、独立开发者、小团队。不适合：完全不想碰服务器的纯小白（除非直接用云版）、需要极其复杂逻辑的开发者（不如直接写代码）。

打分：8/10。它把 AI 自动化这块做得很好，门槛相对低。扣 2 分因为自建部署有一定门槛，且部分高级功能需要云版付费。

## 未来趋势

① 所处阶段：成熟稳定期——n8n 已经运行 7 年，现在集成了 AI 后迎来第二春；② 6-12 个月：AI 模块会越来越智能，可能实现"说人话就生成工作流"；③ 关注度：4/5，自动化领域的头号选手之一。
