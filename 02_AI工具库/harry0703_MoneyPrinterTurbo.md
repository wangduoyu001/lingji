# MoneyPrinterTurbo — 一句话生成高清短视频

> ⭐ 90,280 | 📅 2026-06-20 | [GitHub](https://github.com/harry0703/MoneyPrinterTurbo)

## 干什么

MoneyPrinterTurbo（这名字直译就是"印钞机涡轮版"）是一个帮你自动生产短视频的工具。你只需要提供一个主题或关键词——比如"如何增加生活的乐趣"——它就会全自动帮你完成：写文案 → 找视频素材 → 配音 → 加字幕 → 配背景音乐 → 合成一个高清短视频。全部流程不需要你动手。

它就像一个"短视频工厂流水线"：你输入订单（主题），等几分钟，成品视频就出来了。支持竖屏 9:16（适合抖音/TikTok）和横屏 16:9（适合 YouTube）两种格式。

项目是中国人开发的，天然支持中文文案和中文语音合成，在中文短视频场景下体验最好。

## 能实现什么效果

对想做短视频但不会剪辑的人来说，这个工具可以直接让你从 0 到 1。你不需要学 Premiere、不需要找素材网站、不需要练配音——只要有个主题想法，就能产出看起来还不错的视频。

实际产出质量：视频画面来自 Pexels/Pixabay 等免费素材库，画质高清但没有太强的"定制感"（毕竟素材是公共的）；AI 写的文案水平中等偏上（取决于你用哪个大模型）；配音效果还行（Edge TTS 免费版够用，Azure TTS 付费版效果更好）。

如果大量生产（比如一天做 20 条），虽然单条质量不算顶尖，但"量大管饱"——适合做内容矩阵、批量测试选题、快速验证视频方向。

## 怎么用

- **Windows 一键包**（最简单）：下载解压 → 双击 `update.bat` 更新 → 双击 `start.bat` → 浏览器自动打开界面 → 输入主题 → 点生成。
- **Docker 部署**：`docker compose -f docker-compose.release.yml up` → 访问 http://127.0.0.1:8501。
- **Web 界面操作**：输入视频主题 → 选横竖屏 → 选配音 → 调整字幕样式 → 点"生成视频" → 等着（几分钟到十几分钟看视频长度）。
- **批量生成**：一次生成多个版本 → 选最满意的那个。
- **命令行生成**（不需要浏览器）：`python cli.py --video-subject "金钱的作用"`。
- **一键发布**：配置好 Upload-Post 账号后，生成完自动上传到 TikTok/Instagram/YouTube Shorts。

## 运行位置

- **本地电脑**：Windows 10+（推荐）、macOS 11+、主流 Linux
- **Docker**：任何能跑 Docker 的环境
- **Google Colab**：免安装在线体验

## 需要准备什么

- 免费开源（MIT 协议）
- 需要一个大模型的 API Key（用于生成文案）：支持 OpenAI、DeepSeek、通义千问、Ollama 等十几种，选一个最便宜的就行
- 可选：Pexels/Pixabay API Key（用于获取视频素材，免费注册即可）
- 可选：Azure Speech Key（用于更高质量的配音，不用也行——Edge TTS 免费版够用）
- 电脑配置：最低 4 核 CPU + 4GB 内存就能跑；如果要用本地 Whisper 做字幕，建议有独显
- Windows 注意：路径不要含中文或空格

## 配合什么软件

- 独立使用，不需要其他软件
- 生成后视频可在任何视频平台发布（抖音、TikTok、YouTube、快手等）
- 可选配合 Upload-Post 实现自动分发

## 客观评价

**优点**：上手极简单——Windows 一键包解压就用；免费素材库不用担心版权问题；中文支持好（中国开发者做的，文案和配音中文效果最好）；支持批量生成和自动发布，适合做视频矩阵；社区活跃（9 万+ star），遇到问题容易找到解决方案。

**缺点**：视频素材来自公共免费库，看多了会有"千篇一律"的感觉（都是类似的风景/人物素材）；AI 写的文案质量不稳定——有时很好有时很水，取决于用的模型和主题；生成的视频有"AI 味"——节奏感、画面切换等不如人工剪辑自然；复杂的创意视频做不了（比如需要特定场景、特定人物的内容）。

**适合谁**：想做短视频但不会剪辑的新手、需要批量生产内容做矩阵的人、想快速测试视频选题是否受欢迎的创作者。**不适合**：追求高品质原创视频的专业创作者、需要真人出镜的视频、复杂叙事类视频。

**评分 7/10**：对于"快速量产短视频"这个细分需求，几乎是最佳工具。扣分在于素材来源有限导致的同质化问题。

## 未来趋势

项目处于**成熟稳定期**，核心功能已经完善。随着 AI 视频生成技术快速发展（Sora、可灵等），未来可能会集成 AI 生成视频素材的能力，大幅提升内容独特性。

**关注度 4/5**：短视频 + AI 是黄金赛道，这个项目在中国开发者圈影响力巨大。
