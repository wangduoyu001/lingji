# AnythingLLM

> ⭐ 61,847 | 📅 2026-06-20 | [GitHub](https://github.com/Mintplex-Labs/anything-llm)
>
> 💡 **怎么标记**：改上面 `interest` 数字 → 3=必装 2=想试 1=观望 0=跳完按 Ctrl+S 保存

## 干什么
AnythingLLM 就像一个"私人 AI 办公室"——你把文档丢进去，它变成你的专属 AI 助手，能跟你的文档对话、跑 AI Agent 自动干活、管理团队权限，而且全部数据都在你电脑上不出门（就像请了个只为你服务的私人秘书，不会把你的文件泄露给任何人）。没有它之前，要么用 ChatGPT 但数据上传到美国服务器（隐私风险），要么自己搭 RAG 系统但技术门槛太高。AnythingLLM 一键安装，双击打开就能用，界面跟 ChatGPT 一样简单，但底层是个完整的 AI 工作台——知识库、Agent、定时任务、多用户管理全都有。

## 能实现什么效果
装完 AnythingLLM，你就拥有了一个"本地版 ChatGPT + 知识库 + Agent 工作台"。上传直播话术文档后，直接问"这个话术的核心卖点是什么"，AI 从你的文档里精准回答。设置定时 Agent，每天自动总结直播数据、生成运营报告。创建多个"工作区"（类似文件夹），直播话术、竞品分析、运营数据各一个区，互不干扰。它的动态模型路由功能还能根据问题复杂度自动选最合适的模型——简单问题用本地免费模型（Ollama），复杂问题用 Claude/GPT（付费但质量高），帮你省钱又保质量。

## 怎么用
1. **直播话术问答**：上传话术文档 → Ask "这段话术为什么有效" → AI 从文档里回答并标注出处
2. **自动生成运营日报**：设定 Agent 定时任务 → 每天自动抓取数据+生成报告 → 你只看结果
3. **多工作区管理**：直播话术区、竞品分析区、个人笔记区 → 不同主题分开管理
4. **省钱模型路由**：简单问题走 Ollama（免费）→ 复杂问题走 Claude（付费但精准）→ 自动切换
5. **团队协作**：Docker 版支持多用户 → 给运营团队成员各自账号 → 权限隔离

## 运行位置
本地电脑直接运行，支持 Windows、macOS、Linux 三大平台。桌面版双击安装就能用（像装普通软件一样）。也有 Docker 版本用于团队部署或多用户场景。还有云端部署选项（AWS、Digital Ocean 等）。数据完全本地存储，模型可以选择本地（Ollama）或云端（OpenAI/Claude/DeepSeek 等）。

## 需要准备什么
① **桌面版完全免费**（MIT 许可证），Docker 版也免费。② 不需要注册账号（本地使用）。③ 如果用本地模型（Ollama），不需要 API Key，完全免费。④ 如果用云端模型（Claude/GPT），需要对应的 API Key，按用量付费。⑤ 电脑配置：4GB 内存起步（用本地模型需要更多），你的 16GB 内存完全够用。⑥ 桌面版安装就是普通软件安装流程，不需要 Python/Node.js/Docker。⑦ 如果用 Ollama 当后端，需要先装 Ollama。

## 配合什么软件
最佳搭配：Ollama（免费本地模型后端）、Claude/GPT API（高质量云端模型）、LanceDB（内置向量数据库，不需要额外装）。独立使用完全可以，自带完整界面和功能。支持 MCP 协议，可以接到其他 AI 工具。还有 Chrome 浏览器扩展可以抓网页内容直接入库。

## 客观评价
**优点**：安装极其简单（桌面版双击就装），界面像 ChatGPT 一样直观（非技术用户也能用），功能全面（知识库 + Agent + 定时任务 + 多用户 + 模型路由），免费开源（MIT 许可证），数据完全本地可控，模型选择灵活（20+ 提供商随便切换）。**缺点**：桌面版不支持多用户（只有 Docker 版支持），Agent 功能还比较基础（不如专业 Agent 工具强），大文档处理偶尔卡顿，社区规模不如 RAGFlow 大。**适合谁**：想要简单搭建本地 AI 知识库的人、不想折腾技术只想用的人、需要 Agent 定时自动执行任务的人。**不适合谁**：需要高级 Agent 功能的人（用 Dify/n8n 更好）、需要多用户团队协作但不想装 Docker 的人。**评分：8/10**。理由：个人本地 AI 知识库的最佳选择，简单好用功能全，免费还隐私。

## 未来趋势
① 项目处于**快速增长**阶段，stars 半年涨了 2 万多，功能持续增加。② 6-12 月：Agent 能力增强（可视化工作流编辑器更完善）、更多模型支持、桌面版可能支持多用户。③ 关注度评分：**4/5**，本地 AI 应用热门赛道，AnythingLLM 定位清晰。
