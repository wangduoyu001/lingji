## 干什么

OpenAlice 是一个"AI 交易代理"开源项目，口号是"你的一人华尔街"。它能分析股票、加密货币、大宗商品、外汇和宏观经济数据，然后自己判断买卖时机、管理仓位（你持有哪些资产、各占多少比例）、执行交易。

它的设计理念是"AI 负责决策，你负责审批"——每笔交易在执行前都需要你明确批准，而且所有操作都有"类 Git 的版本历史"（可以回溯每一笔交易是谁、在什么时间、基于什么理由执行的）。这就像给你配了一个"AI 交易员"，但它每做一次决策都要向你汇报，你随时可以喊停，不会擅自乱来。

技术上，OpenAlice 分为两个长期运行的进程：Alice 进程（负责分析、决策、跟你说结果）和 UTA 服务（负责跟券商对接、执行订单、管理仓位）。这两个进程可以跑在同一台电脑上，也可以分开（UTA 服务可以部署在你更信任的设备上，比如家用服务器），类似"硬件钱包"的设计思路——最敏感的部分（券商凭证）是隔离的。

## 能实现什么效果

装上 OpenAlice 之后，你相当于有了一个"24 小时不睡觉的 AI 交易助手"。原来你要自己刷新闻、看 K 线图、判断买入卖出时机，现在可以把这些工作交给 AI，你只需要每天花 10 分钟审批它的交易建议就行了。对于有多种资产（比如同时持有美股+加密货币+外汇）的人，原来要在多个券商 App 之间切换，现在 OpenAlice 的统一交易账户（UTA）把所有券商整合到一个界面里。

举个例子：你持有苹果股票（AAPL），OpenAlice 会持续监控新闻、财报、分析师预测、技术指标。如果它判断"苹果下周要发财报，根据历史数据，发财报前 3 天通常会跌 2-3%，建议先减仓 30%"，它会把这个建议推送到你的"收件箱"（OpenAlice 的 Web 界面里有一个专门收 AI 消息的地方），你看了觉得有道理，点"批准"，它就自动执行卖出操作。如果觉得不对，点"拒绝"就行。

对于想做"量化交易"（用程序自动交易）但没有编程团队的人，OpenAlice 也很有价值。它支持定时任务（用 cron 表达式，一种定时任务配置语法），比如"每天早上 9 点自动分析我的持仓，发一份报告到收件箱"，这个功能可以帮你实现"半自动交易"——AI 负责分析，你负责最终决策。

## 怎么用

- **本地安装（推荐给会技术的用户）**：先装好 Node.js 22+、pnpm 10+、Git，然后 `git clone https://github.com/TraderAlice/OpenAlice.git` 克隆仓库，`pnpm install` 安装依赖，`pnpm dev` 启动。启动后打开终端输出的 UI 地址（默认 `http://localhost:5173`），就能用了。需要本机先装好 Claude Code CLI 并登录（支持 Claude Pro/Max 订阅，不需要单独 API Key）
- **服务器部署（推荐给想 24 小时运行的用户）**：用 Docker 一键部署（`docker compose up -d --build`），镜像里已经内置了 Claude Code 和 Codex CLI，不用在服务器上装依赖。首次启动会生成一个管理员令牌（打印在终端里），用这个令牌登录 Web 界面
- **远程访问**：如果要在公司或手机上访问家里的 OpenAlice，推荐用 Tailscale（一种虚拟专用网络，能把多台设备连成一个私有的小网络）或 VPN，最安全。也可以配置反向代理（用 Caddy 或 Nginx），但一定要加额外认证（因为这是一个能操作你真实资金的系统，不能裸奔在公网上）
- **开始使用**：打开 Web UI → 点"聊天"→ 跟 Alice 说"帮我分析一下苹果股票的持仓风险"→ 看它输出的分析报告 → 如果满意，可以让它"帮我减仓 30%"
- **配置数据源**：默认用官方的 TraderHub（低频数据，开箱即用，不需要配置 API Key）。如果需要实时数据或更多品种，可以在设置里配置自己的数据供应商 Key（比如 CCXT、Alpaca、盈透证券等）

## 运行位置

- 🖥️ **本机（推荐）**：在装了 Node.js 的电脑上跑，延迟最低，控制感最强
- 🖥️ **服务器（Docker）**：用 `docker compose up -d` 部署在 VPS 或常开服务器上，可以 24 小时运行（适合需要定时任务、随时远程访问的场景）
- 📱 **手机访问**：通过 Tailscale 或 VPN 访问服务器上的 OpenAlice，目前没有原生手机 App，用手机浏览器访问 Web UI 就行
- 支持 Windows、macOS、Linux。Windows 用户需要安装 Git for Windows（提供 bash 环境），或者直接在 WSL2（Windows 的 Linux 子系统）里跑

## 需要准备什么

- 💰 **要钱吗**：OpenAlice 本身是免费开源的（AGPL-3.0 协议）。但是——
  - 需要 Claude Code CLI（可以用 Claude Pro/Max 订阅，约每月 20 美元；也可以用 Anthropic API Key，按量付费）
  - 需要券商账户（比如做美股需要开 Alpaca 或盈透证券账户，做加密货币需要开 Binance 或 Bybit 账户）。这些是真实交易账户，往里充钱才能实盘交易
  - 官方 TraderHub 提供低频数据免费使用，实时数据需要自己配置数据供应商（可能有费用）
- 🔑 **API Key**：Claude Code CLI 可以用订阅登录（不需要 API Key），券商 API 需要自己去各券商网站申请（通常需要身份认证）
- 💻 **电脑配置**：8GB 内存就够跑 OpenAlice 本身，但如果要做大量数据分析，16GB 以上更舒服。需要 2GB 以上磁盘空间（Docker 镜像约 1.5GB）
- 📦 **要装什么**：Node.js 22+、pnpm 10+、Git、Claude Code CLI。Windows 额外需要 Git for Windows
- ⚠️ **风险提示**：这是实验性软件，作者明确说"除非你完全理解并接受相关风险，否则不要将其用于真实资金的实盘交易"。AI 的判断可能出错，你可能会亏钱

## 配合什么软件

- **Claude Code CLI**：OpenAlice 的"大脑"，AI 分析能力来自这里。需要本机安装并登录
- **券商平台**：CCXT（支持 100+ 交易所）、Alpaca（美股）、盈透证券（全球股票）、Longbridge 长桥（港股美股 A 股）等
- **数据源**：官方 TraderHub（免费低频数据）、用户自建数据源、券商实时数据
- **Tailscale / VPN**：如果想要远程访问，这是最安全的方案
- **可以独立运行**：OpenAlice 是完整的系统，不需要配合其他软件。但对接券商时需要对应券商的账户

## 客观评价

**优点**：
- 设计理念好："AI 决策 + 人工审批"比"完全自动交易"安全，类 Git 的交易历史让人放心
- 全品类覆盖（股票/加密货币/大宗商品/外汇/宏观），一个工具管所有资产，不用在多个 App 之间切换
- 开源免费（AGPL-3.0），代码透明，不用担心"后台暗箱操作"
- 架构设计合理（Alice 进程和 UTA 服务分离，券商凭证隔离），安全性比把 API Key 写进脚本里高得多
- 支持定时任务 + 无头工作区（AI 自己完成任务后推送结果到收件箱），可以实现"半自动化"
- 中文社区支持好（有 QQ 群、中文文档），对中国用户友好

**缺点/坑**：
- ⚠️ **最大的坑：金融风险**。AI 的判断可能出错，历史表现不代表未来收益，你可能会亏钱。作者明确免责，使用需自行承担风险
- 安装门槛高：需要会 Node.js、pnpm、Git、Docker（至少会一样），纯小白装不上。目前还没有桌面安装包（作者在开发中了）
- 实时数据需要自己配置数据源，官方 TraderHub 只提供低频数据（做日内交易的人需要自己搞定数据源）
- 项目处于活跃开发阶段，可能有 Bug 或破坏性变更（装了之后需要跟着更新）
- 不开源合并外部 PR（作者明确说了不接受外部 PR），社区贡献只能体现在 Issue 讨论里
- 信息有限：我无法实际运行它测试，以上评价基于 README，可能有遗漏

**适合谁**：有一定技术能力、想用 AI 辅助做交易决策的人、已经有编程基础能自己装好这个系统的人、做模拟交易（不花真钱）练手的人。

**不适合谁**：完全不懂编程的人（装不上）、风险承受能力低的人（AI 可能亏钱）、想要"完全自动赚钱、不用我管"的人（OpenAlice 的设计是"人工审批"，不是"完全自动"）。

**评分**：7/10 — 设计理念好、功能全面，但安装门槛高、金融风险需要警惕
